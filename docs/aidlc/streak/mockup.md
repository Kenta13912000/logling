# UI モック：連続記録とボーナス（streak）

見た目は [mockup.html](mockup.html) で確認する（ファイルをブラウザで開くだけ。外部への通信はしない）。色・フォント・ボタンの大きさは `diary-exp` の [mockup.md](../diary-exp/mockup.md) と同じ。

## 方針

| 項目               | 内容                                                                                                  |
| ------------------ | ----------------------------------------------------------------------------------------------------- |
| 置き場所           | ホームのステータス（名前・レベル・経験値のバー）の下に、🔥 の帯を加える。振り返りのページには出さない |
| 帯の 1 行目        | 今の連続日数。今日まだ書いていないときは、今日書くと何日になるか                                      |
| 帯の 2 行目        | 次の区切りまであと何日か、と届くと入るボーナス                                                        |
| 「あと何日」       | 今日を含めて数える（今日まだ書いていなければ、今日の分も 1 日に入る）                                 |
| ボーナスのお知らせ | いつもの「✨ +10 経験値！」の下に、「🔥 7 日連続！ボーナス +20」の行を加える（1 つのお知らせに 2 行） |
| 消す前の確認       | 減る経験値はボーナスを含めた合計。ボーナスが付いているときだけ、内訳を小さく出す                      |

## 画面と文言

| 画面                              | 対象の AC   | 主な文言                                                                                                             |
| --------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------- |
| 1. 今日まだ書いていない（連続中） | AC-2, AC-7  | 「🔥 4 日連続中。今日書くと 5 日！」／「あと 3 日で 7 日連続。ボーナス +20」                                         |
| 2. 今日書いた（連続中）           | AC-1, AC-7  | 「🔥 5 日連続」／「あと 2 日で 7 日連続。ボーナス +20」                                                              |
| 3. 昨日も今日も書いていない       | AC-3, AC-7  | 「🔥 今日書くと 1 日目！」／「あと 3 日で 3 日連続。ボーナス +10」                                                   |
| 4. 区切りに届いた                 | AC-9, AC-10 | お知らせ「✨ +10 経験値！」「🔥 7 日連続！ボーナス +20」。帯は「🔥 7 日連続」「あと 7 日で 14 日連続。ボーナス +30」 |
| 5. ボーナスの付いた日記を消す     | AC-15       | 「消すと経験値が 30 減るよ。」／「（日記の 10 と、7 日連続のボーナス 20）」                                          |

- 後から書いた日記で連続がつながったときも、帯の日数は同じように変わる（ボーナスのお知らせは出ない）
- レベルが上がったときは、お知らせのあとに `diary-exp` と同じレベルアップのお知らせを出す

## 色

`diary-exp` と同じ。🔥 の帯は、経験値のバーの下地と同じ薄いはちみつ色（`#F6E7CF`）にする。

## 判断メモ

- モックへのゲートでの判断：指摘なしで承認（「あと何日」は今日を含めて数える。ボーナスのお知らせは 1 つに 2 行。「0 日連続」とは出さない）
