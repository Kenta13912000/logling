logling UI モック（streak）

スマホ（幅 375px）での見た目。例として、今日を 2026年11月8日（日）とする。ボタンなどは見た目だけで、押しても動かない。 新しく加えるのは、ステータスの下の「🔥」の帯と、お知らせのボーナスの行、消す前の確認の内訳。
