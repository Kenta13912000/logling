## 判断メモ

- C は、`diary-exp`・`diary-history` の ⑧ と同じく、テストのある動きを AC にした。テストはすでにあったので、テストの名前に AC-23 を付け、帯の名前も明示的に確かめるようにした
- D・E は見た目、またはこれまでの処理の上に乗せた動きのため、要件定義書への記録だけにした
- H は、公開中のサイトへの確認がマージとデプロイのあとでないとできないため、PR のマージ後の後片付けと一緒に実行する
- 差分レポートへのゲートでの判断：提案どおりの対応で、指摘なしで承認
- H の実行結果：2026-11-08 に公開中のサイトで E2E テスト 17 件（`diary-exp`・`release`・`diary-history`・`streak`）がすべて通った。記録は別のドキュメントの PR で残した
