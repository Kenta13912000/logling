# Units：連続記録とボーナス（streak）

## U-1：連続記録とボーナス（`src/features/streak/`）

- 含む Story：S-1, S-2, S-3, S-4, S-5, S-6
- 依存：
  - `src/features/home/`（保存データ・ホームの画面。ホームに連続日数を出し、日記を保存するときにボーナスを足す）
  - `src/features/diary/`（日記のデータの形。日記にボーナスの記録を加える）
  - `src/features/character/`（経験値とレベルの計算。ボーナスもいつもの経験値と同じく足す）
  - `src/features/history/`（日記を消すときの減る経験値。ボーナスを含めるようにする）

連続日数の計算・次の区切り・ボーナスの量のきまりは、どれも「連続記録」の話なので、1 つの Unit にまとめる。ホームや振り返りの画面には、この Unit の計算を呼び出す形で組み込む。

### Bolt 計画

- Bolt-1：データの形と計算。連続日数・次の区切り・ボーナスの量・日記ごとの経験値（ボーナスを含む）を求める（AC-4, AC-5, AC-8, AC-11〜AC-14, AC-21）
- Bolt-2：ホームに連続日数と次の区切りを表示する（AC-1〜AC-3, AC-6, AC-7）
- Bolt-3：今日の日記を書いたときにボーナスを入れ、お知らせを出す。ボーナスの付いた日記を消す・書き直すときの扱い（AC-9, AC-10, AC-15〜AC-20）
- Bolt-4：スマホ幅での表示と、連続記録の一連の操作の E2E テスト（AC-22）

### 設計（⑤で追記）

## 実装の順番

| 順番 | Bolt   | 内容                             | 理由                                                                             |
| ---- | ------ | -------------------------------- | -------------------------------------------------------------------------------- |
| 1    | Bolt-1 | データの形と計算                 | 連続日数とボーナスのきまりを最初に固める。画面に依存せず、テストしやすい         |
| 2    | Bolt-2 | ホームの表示                     | 計算ができれば表示できる。ボーナスより先に「何日続いているか」が見えるようにする |
| 3    | Bolt-3 | ボーナスを入れる・消すときの扱い | 保存データと経験値を変える部分。表示ができてから、お知らせと合わせて作る         |
| 4    | Bolt-4 | スマホ対応と E2E テスト          | 画面がそろってから、本物のブラウザで通しで確かめる                               |

## PR の単位

Bolt は 4 つで、`diary-history`（Bolt 5 つ・1 PR）より小さい。ルールどおり、1 ブランチ・1 PR（`feat/streak`）で進める。

## ④ UI モックについて

ホームのステータスの近くに連続日数と次の区切りを出し、日記を保存したときのお知らせにボーナスを加える。画面が変わるので、`diary-history` と同じく HTML のモックを作ることを提案する。

## 判断メモ

- Units へのゲートでの判断：指摘なしで承認（1 ブランチ・1 PR のまま。④ UI モックは HTML で作る）
