# UI モック：日記で経験値（diary-exp）

見た目は [mockup.html](mockup.html) で確認する（ファイルをブラウザで開くだけ。外部への通信はしない）。
このファイルには、モックで決めた方針・文言・色を記録する。

## 方針

| 項目             | 内容                                                                           |
| ---------------- | ------------------------------------------------------------------------------ |
| キャラクター     | 絵文字 1 つ（🐣）を表示する。本格的な見た目は `character-evolution`            |
| 文言             | キャラクターが話しかける口調（「〜してね」「きかせて！」）                     |
| 色合い           | やわらかい暖色系（下の「色」）                                                 |
| レイアウト       | スマホ幅で縦 1 列。上にキャラクターのステータス、下に日記。PC では中央に寄せる |
| 経験値の数（仮） | モックでは「1 件で 10」「レベル 2 まで 30」と仮に置く。⑤ 設計で決める          |

## 画面と文言

| 画面                      | 対象の AC          | 主な文言                                                                                                                    |
| ------------------------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| 1. 名前を付ける           | AC-1〜AC-4         | 「はじめまして！名前をつけてくれる？」／見出し「名前（10 文字まで）」／ボタン「この名前にする」                             |
| 2. 今日の日記を書く       | AC-5〜AC-8, AC-10  | 「今日はどんな一日だった？きかせて！」／ボタン「日記をのこす」／文字数「0 / 2000」                                          |
| 3. 保存したとき           | AC-9, AC-11〜AC-13 | 「✨ +10 経験値！」（2〜3 秒）／レベルアップ時「<名前> が レベル <N> になった！」「これからもよろしくね」／ボタン「とじる」 |
| 4. 今日の日記を書いたあと | AC-14, AC-15       | 「今日も書いてくれてありがとう！また明日ね」／「次の日記は、明日の朝 4 時から書けるよ」                                     |

### エラーの文言

| 場面                     | 文言                                      |
| ------------------------ | ----------------------------------------- |
| 名前が空・空白だけ       | ⚠ 名前を入れてね                          |
| 名前が 11 文字以上       | ⚠ 名前は 10 文字までにしてね              |
| 本文が空・空白や改行だけ | ⚠ なにか書いてくれるとうれしいな          |
| 本文が 2001 文字以上     | ⚠ 2000 文字までにしてね（いま 2034 文字） |

### 表示のきまり

- 日付は朝 4 時区切りの「日記の日付」を表示する（深夜 1 時なら前の日の日付）
- ステータスには、絵文字・名前・レベル・経験値のバー・次のレベルまでの残りを表示する
- レベルアップのお知らせは「とじる」を押すまで表示する。レベルが上がらなかったときは出さない

## 色

| 用途             | 色                     | メモ                                   |
| ---------------- | ---------------------- | -------------------------------------- |
| 背景             | クリーム `#FFF8EC`     |                                        |
| 文字             | こげ茶 `#3F2D1C`       | 背景との差を十分にとり、読みやすくする |
| ボタン           | 濃いオレンジ `#C2410C` | 白い文字が読める濃さにする             |
| 経験値のバー     | 山吹色 `#D97706`       | バーの地の色と見分けられる濃さにする   |
| 注意のメッセージ | 赤茶 `#B42318`         | 色だけに頼らず「⚠」も付ける            |

## 使いやすさのための決めごと

- ボタンや入力欄は、指で押しやすい高さ（44px 以上）にする
- 入力欄には見出しを付け、画面の読み上げ機能でもわかるようにする
- レベルアップのお知らせを開いたら「とじる」にフォーカスを移し、閉じたら元の場所に戻す

## 判断メモ

- 作成前に確認した点：モックはブラウザで見られる HTML で作る／キャラクターは絵文字 1 つ／文言はキャラクターが話しかける口調／色はやわらかい暖色系
- モックへのゲートでの判断：指摘なしで承認（経験値の数は仮のまま、⑤ 設計で決める）
- Bolt-1 の ⑤ で修正：お知らせの「けいけんち」を漢字の「経験値」に変更
