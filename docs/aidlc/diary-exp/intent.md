# Intent：日記で経験値（diary-exp）

日記が続かない人が、日記を書くたびに自分で名前を付けたキャラクターが育つのを見て、毎日書く理由を持てるようにする。

## 対象ユーザー

- 毎日日記を書きたいが、書くのを続けられない人
- 主にスマホで、寝る前などのすき間時間に短く書く
- ログインなどの準備なしに、すぐ試したい

## SC（成功条件）

- SC-1：初めて開いた人が、キャラクターに名前を付け、その日の日記を書いて保存できる
- SC-2：日記を保存すると、キャラクターに一定の経験値が入り、画面の経験値の表示が増える
- SC-3：経験値が一定量たまるとレベルが上がり、レベルアップのお知らせが出て、レベルの表示が変わる
- SC-4：その日の日記を書いた後は同じ日に 2 件目を書けず、代わりにその日に書いた日記が表示される
- SC-5：ブラウザを閉じて開き直しても、キャラクターの名前・レベル・経験値と、書いた日記が残っている
- SC-6：スマホの画面幅（幅 375px 程度）で、横スクロールなしに一連の操作ができる

## 前提

- データはその端末のブラウザ内に保存する。別の端末やブラウザとは共有しない
  - ブラウザのデータを消したり、シークレットモードで開いたりすると日記も消える。この弱点への対策（ログインとクラウド保存）は `account-sync` で行う
- 「1 日」は端末の時刻で **朝 4 時** に区切る（例：深夜 1 時に書いた日記は前の日の日記として扱う）
- 経験値は 1 件ごとに一定で、日記の長さには関係しない

## スコープ外

| 内容                                             | 扱う機能                   |
| ------------------------------------------------ | -------------------------- |
| キャラクターの見た目の変化                       | `character-evolution`      |
| 日記の一覧・編集・削除                           | `diary-history`            |
| 連続で書いた日数の表示とボーナス経験値           | `streak`                   |
| ログイン・クラウド保存・端末をまたいだ利用       | `account-sync`             |
| 公開（Vercel へのデプロイ）                      | `release`                  |
| キャラクター名の変更・複数キャラ・アニメーション | 未定（必要になったら検討） |

## 判断メモ

- 作成前に確認した点：日記は 1 日 1 件だけ／経験値は 1 件ごとに一定／キャラクターにはユーザーが名前を付ける／レベルアップはお知らせとレベル表示の変化のみ（アニメーションなし）／見た目の変化はロードマップどおり `character-evolution` で扱う
- 修正を依頼した点：1 日の区切りを 0 時から朝 4 時に変更（夜ふかしして書く人の日記を前の日として扱うため）／SC-4 で「今日はもう書いた」はその日の日記を表示して伝える／ブラウザ内保存の弱点は `account-sync` で対策すると明記
- Intent へのゲートでの判断：上記の修正を反映して承認
