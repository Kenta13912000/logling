## 判断メモ

- A〜F は、当初「仕様を更新し、テストのないものは次回へ回す」を提案したが、「同じ Intent ならテストすべき」「次回とは具体的にいつか」との指摘を受け、今回 AC とテストを追加することにした。「次回へ回す」は置き場所を決めないと忘れられやすいため、次回へ回したもの（M）はロードマップに記載した
- L は「CI に本番ビルドを入れるとどうなるか」を確認したうえで、今回入れることにした
- 差分レポートへのゲートでの判断：上記の対応で承認
