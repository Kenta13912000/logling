# UI モック：キャラクターが日記にコメントする（ai-companion）

見た目は [mockup.html](mockup.html) で確認する（ファイルをブラウザで開くだけ。外部への通信はしない）。色・ボタン・暗い色は `settings` の [mockup.md](../settings/mockup.md) と同じ。

## 方針

| 項目                   | 内容                                                                                                                                           |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 「設定」の置き場所     | 「キャラクター」のすぐ下に「キャラクターのコメント」。中身は「日記へのコメント」の切りかえと、説明の 1 行                                      |
| オンにするときの確認   | 確認の窓（`<dialog>`）。見出し「コメントをオンにする？」、送るもの・送り先・送ったものの扱い（説明ページへのリンク）、「オンにする」「やめる」 |
| オフにするとき         | 確認なしで、すぐオフ                                                                                                                           |
| コメントの吹き出し     | キャラクターの絵（今の段階）と、薄いオレンジの地の吹き出し。吹き出しの上に小さく「<名前>より」                                                 |
| ホームでの場所         | 案 A：今のお礼の吹き出し「今日も書いてくれてありがとう！また明日ね」は残し、日記の本文の下にコメントの吹き出しを足す（画面 4）                 |
| 振り返りでの場所       | 各日記の本文の下（「書き直す」「消す」の上）に、少し小さな絵と吹き出し                                                                         |
| 作っている間・上限など | 同じ吹き出しの中に文を出す。作っている間は読み上げられる（`role="status"`）                                                                    |

## 判断メモ

- ホームでのコメントの場所は案 A（今のお礼の吹き出しは残し、本文の下にコメントを足す）にした（開発者の判断。作っている間や作れなかったときもお礼が出ていて、今の画面との違いが小さいため）
- モックへのゲートでの判断：上の点を選んで承認（確認の窓の文、吹き出しの「<名前>より」、振り返りの場所はそのまま）
