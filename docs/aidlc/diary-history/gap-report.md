## 判断メモ

- A〜C は、`diary-exp` の ⑧ での指摘（同じ Intent ならテストすべき）にならい、テストのある動きを AC にした。テストはすでにあったので、テスト名に AC の ID を付けた
- M は、公開中のサイトへの確認がマージとデプロイのあとでないとできないため、PR のマージ後の後片付けと一緒に実行する
- 差分レポートへのゲートでの判断：提案どおりの対応で、指摘なしで承認
