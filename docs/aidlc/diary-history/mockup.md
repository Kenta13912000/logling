# UI モック：日記の振り返り（diary-history）

見た目は [mockup.html](mockup.html) で確認する（ファイルをブラウザで開くだけ。外部への通信はしない）。色・フォント・ボタンの大きさは `diary-exp` の [mockup.md](../diary-exp/mockup.md) と同じ。

## 方針

| 項目                 | 内容                                                                                                    |
| -------------------- | ------------------------------------------------------------------------------------------------------- |
| ページ               | ホームとは別のページ（`/history`）。上の帯の左に「‹ ホーム」                                            |
| 入口                 | ホームの上の帯の右に「ふりかえる ›」。名前を付けたあとのどの画面でも出す                                |
| 一覧                 | 日付の新しい順に、1 日 1 枚のカード。日付は「11月7日（土）」の形（年は省く）                            |
| 最近 7 日            | 日記のカードに「書き直す」「消す」。日記がない日は点線のカードで「この日の日記を書く」                  |
| 8 日以上前           | 区切りの文「ここから下は 8 日以上前の日記（読むだけ）」のあとに、ボタンのないカード。空いた日は出さない |
| 後から書いた日記     | 日付の横に「あとから」の印                                                                              |
| 書き直す・後から書く | 別の画面に移らず、カードの中が入力欄に変わる                                                            |
| 消す                 | 画面の中央に確認の窓（`diary-exp` のレベルアップのお知らせと同じ `<dialog>`）                           |

## 画面と文言

| 画面                  | 対象の AC              | 主な文言                                                                                                                                                                                                                             |
| --------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1. ホーム             | AC-1                   | 「ふりかえる ›」                                                                                                                                                                                                                     |
| 2. ふりかえり（一覧） | AC-2, 3, 6, 10, 14, 18 | 見出し「ふりかえり」／「最近 7 日の日記は、書き直したり消したりできるよ」／空いた日「この日はまだ書いていないよ（あとから書くと +5 経験値）」「この日の日記を書く」／「あとから」／「― ここから下は 8 日以上前の日記（読むだけ） ―」 |
| 3. 書き直す           | AC-6〜9                | ボタン「保存する」「やめる」                                                                                                                                                                                                         |
| 4. 後から書く         | AC-14〜17              | 「<月>月<日>日は、どんな一日だった？」／入力欄の案内「思い出せることを書いてみよう」／ボタン「日記をのこす」「やめる」／保存後「✨ +5 経験値！」                                                                                     |
| 5. 消す前の確認       | AC-10〜12              | 「<月>月<日>日の日記を消す？」／「消すと経験値が <10 または 5> 減るよ。」／下がる場合「<名前> のレベルが <N> から <M> に下がるよ。」／「消した日記は元に戻せないよ」／ボタン「消す」「やめる」                                       |
| 6. 日記がまだないとき | AC-4, 5                | 「まだ日記がないよ。ホームで今日の日記を書いてみよう」／名前がないとき「ホームで名前を付けてね」／ボタン「ホームへ」                                                                                                                 |

- 本文のエラーの文言（空・2001 文字以上）と、保存に失敗したときの文言は `diary-exp` と同じ
- 書き直して保存したときは、お知らせ（トースト）を出さない（経験値が変わらないため）

## 色

`diary-exp` と同じ。消すボタンと、レベルが下がる注意の文は、注意の色（赤茶 `#B42318`）にする。

## 判断メモ

- モックへのゲートでの判断：指摘なしで承認（一覧の日付は年を省く。書き直したときはお知らせを出さない）
