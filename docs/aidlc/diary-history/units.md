# Units：日記の振り返り（diary-history）

## 全体像

```
U-1 振り返り（src/features/history/）
 ├─ 使う：U-1 キャラクター（diary-exp。経験値とレベルの計算）
 ├─ 使う：U-2 日記（diary-exp。日記の型・本文の検証・入力欄）
 └─ 使う：U-3 ホーム画面（diary-exp。保存データの読み書き）
```

- 新しく作る Unit は「振り返り」の 1 つ。振り返りのページのロジックと画面を受け持つ
- `diary-exp` で作った Unit にも、次の変更を加える（どの Bolt で変えるかは Bolt 計画に書く）
  - 日記（`src/features/diary/`）：日記ごとに「その日に書いたか、後から書いたか」を持たせる。入力欄の呼びかけの文言を、書き直し・後から書くときにも使えるようにする
  - キャラクター（`src/features/character/`）：後から書いた日記の経験値（5）を加える。経験値を減らす計算を加える
  - ホーム画面（`src/features/home/`）：「ふりかえる」のリンクを置く。保存データの読み込みで、これまでの日記（書き方の記録がない日記）を受け入れる

## U-1：振り返り（`src/features/history/`）

- 含む Story：S-1, S-2, S-3, S-4, S-5, S-6, S-7
- 依存：`diary-exp` のキャラクター・日記・ホーム画面
- 受け持つこと：一覧の組み立て（新しい順、最近の空いた日を含む）、書き直し・削除・後から書けるかの判定（最近 7 日）、書き直し・削除・後から書いたときの保存データと経験値の計算、振り返りのページの画面、`src/app/history/page.tsx` からの呼び出し

### Bolt 計画

- Bolt-1：データの形と計算。日記の書き方の記録・後から書いた日記の経験値・これまでの日記の扱い・「最近 7 日」の判定・一覧の組み立て・書き直し／削除／後から書いたときの計算（ロジックのみ。AC-7, AC-10〜AC-12 の計算, AC-15 の計算, AC-18, AC-19, AC-21）
- Bolt-2：振り返りのページ（読むだけ）とホームからのリンク（AC-1〜AC-5, AC-20 の読み込み）
- Bolt-3：書き直しと削除（画面と保存）（AC-6〜AC-13, AC-20, AC-22）
- Bolt-4：後から書く（画面と保存）（AC-14〜AC-17, AC-20, AC-22）
- Bolt-5：スマホ幅での表示と、振り返りの一連の操作の E2E テスト（AC-23）

### 設計（⑤で追記）

#### Bolt-1：データの形と計算

**日記のデータの形（`src/features/diary/diary.ts` を変える）**

```ts
type DiaryEntry = {
  date: string; // 日記の日付（朝 4 時区切り）
  body: string;
  createdAt: string; // 保存した時刻
  writtenLater?: true; // 後から書いた日記だけに付ける。ない日記は「その日に書いた日記」
};
```

- 「後から書いた」ときだけ `writtenLater: true` を付け、それ以外は何も付けない
  - 理由：`diary-exp` で保存した日記には、この印がない。印がなければ「その日に書いた日記」と読めば、これまでのデータを書き換えずにそのまま使える（AC-21）
- 保存データの読み込み（`src/features/home/save-data.ts`）では、`writtenLater` が「ない」か「`true`」のときだけ正しい形として受け入れる。それ以外（例：`false` や文字列）は壊れたデータとして扱う
- `entries` は、これまでどおり日付の古い順に並べる。後から書いた日記は、日付の順の正しい位置に入れる

**経験値のきまり（`src/features/character/character.ts` に加える）**

| 項目               | 値・関数                                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------------------- |
| その日に書いた日記 | 10（今の `EXP_PER_ENTRY`）                                                                                 |
| 後から書いた日記   | 5（`EXP_PER_LATE_ENTRY` を新しく加える）                                                                   |
| 経験値を減らす     | `loseExp(character, amount)`：合計から減らし（0 より下にはしない）、減らす前と後のレベル・下がったかを返す |

- 日記 1 件ぶんの経験値（10 か 5）を求める `expForEntry(entry)` は、日記とキャラクターの両方を知っている振り返りの Unit に置く

**「最近 7 日」の判定（`src/lib/diary-date.ts` に加える。`streak` でも使う）**

| 関数                             | 内容                                                                                    |
| -------------------------------- | --------------------------------------------------------------------------------------- |
| `addDays(date, days)`            | 日記の日付に日数を足す・引く（例：`2026-11-01` に -1 → `2026-10-31`）。月・年をまたげる |
| `isRecentDiaryDate(date, today)` | 今日を含めた最近 7 日（今日〜6 日前）に入るか                                           |

- `RECENT_DAYS = 7` を定数にし、文言（「最近 7 日」）も同じ定数から作る

**振り返りのロジック（`src/features/history/history.ts`。新しく作る）**

| 関数                                            | 内容                                                                                                                                                                  | 対象の AC           |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- |
| `buildHistory(entries, today)`                  | 一覧に並べる項目を、日付の新しい順に返す。最近 7 日は、日記があれば「書き直し・削除できる日記」、今日以外で日記がなければ「空いた日」。それより前は「読むだけの日記」 | AC-2, 3, 14, 18, 19 |
| `expForEntry(entry)`                            | 日記 1 件ぶんの経験値（後から書いた日記は 5、それ以外は 10）                                                                                                          | AC-10, 21           |
| `previewDelete(data, date)`                     | 消したら減る経験値と、消す前・後のレベルを返す（確認の文言に使う。保存はしない）                                                                                      | AC-10, 11           |
| `editEntry(data, date, body, today)`            | 最近 7 日の日記の本文を差し替えた保存データを返す。経験値は変えない                                                                                                   | AC-7                |
| `deleteEntry(data, date, today)`                | 最近 7 日の日記を消し、その日記ぶんの経験値を減らした保存データと、レベルが下がったかを返す                                                                           | AC-12               |
| `writeLaterEntry(data, date, body, today, now)` | 今日より前の最近 6 日で、日記がない日に、後から書いた日記を加え、経験値を 5 足した保存データと、レベルが上がったかを返す                                              | AC-15               |

- どの関数も、元の保存データは書き換えず、新しい保存データを返す（`diary-exp` と同じ作り）
- 最近 7 日の外の日付・すでに日記がある日・今日の日付への後から書く、など、できない操作のときは「失敗」を返し、保存データは変えない（画面でボタンを出さないことに加えて、ロジックの側でも守る）
- 本文の検証は、これまでどおり画面の部品（入力欄）で `validateBody` を使って行う。ここに渡すのは検証済みの本文

**ファイルの置き場所**

```
src/lib/diary-date.ts / diary-date.test.ts        # addDays・isRecentDiaryDate・RECENT_DAYS を加える
src/features/diary/diary.ts                        # DiaryEntry に writtenLater を加える
src/features/character/character.ts / .test.ts     # EXP_PER_LATE_ENTRY・loseExp を加える
src/features/home/save-data.ts / .test.ts          # writtenLater の形のチェックを加える
src/features/history/history.ts / history.test.ts  # 新しく作る
```

**⑥ で書くテスト（例）**

- `addDays`：月末（11/1 → 10/31）・年末（1/1 → 12/31）・足す方向
- `isRecentDiaryDate`：今日が 11/7 なら、11/1〜11/7 は入る、10/31 は入らない
- `loseExp`：合計 75（Lv3）から 10 減らす → 65（Lv2、下がった）／合計 5 から 10 減らす → 0 で止まる
- `buildHistory`：今日 11/7 で、11/7・11/5（後から）・10/31 に日記、11/6 などが空いている例で、並び順と項目の種類
- `expForEntry`：印なし（これまでの日記）→ 10、後から → 5
- `previewDelete`・`deleteEntry`：減る量・レベルの変化・一覧から消えること・範囲外の日付は失敗
- `editEntry`：本文が変わり、経験値は同じ・範囲外は失敗
- `writeLaterEntry`：日付の順の位置に入る・5 足される・レベルアップ・今日・日記がある日・範囲外は失敗
- `save-data`：`writtenLater: true` の日記は読める・印のない日記もそのまま読める・`writtenLater: false` は壊れたデータ

**ADR**

技術の選定を伴う判断はないため、ADR は作らない。保存データの形の変更（`writtenLater` の追加）は、この units.md に記録する。`version` は 1 のまま（印がなくても読めるため）。

#### Bolt-2：振り返りのページ（読むだけ）とホームからのリンク

**ページとファイル**

```
src/app/history/page.tsx                       # HistoryPage を表示するだけ。タブのタイトルは「ふりかえり | logling」
src/features/history/HistoryPage.tsx / .test.tsx   # 'use client' を付ける入口。状態に応じた表示と一覧
src/features/history/HistoryList.tsx / .test.tsx   # 一覧（日記のカード・空いた日のカード・区切りの文）
src/lib/diary-date.ts                          # 一覧用の短い日付「11月7日（土）」を作る formatShortDiaryDate を加える
src/features/home/Home.tsx                     # 上の帯に「ふりかえる ›」のリンクを加える
```

- 保存データと「今日」は、ホームと同じフック（`useSaveData`・`useToday`）を使う。振り返りの Unit がホームの Unit に依存する形になる（③ で決めた依存のとおり）
- ページの移動には、Next.js の `Link` を使う（ページ全体を読み込み直さずに移れる）

**ホームの上の帯（AC-1）**

- キャラクターがいるときだけ、上の帯の右に「ふりかえる ›」（`/history` へのリンク）を出す。名前を付ける前（キャラクターがいない）と、保存データが壊れているときは出さない
- 見出し「logling」（`h1`）はこれまでどおり

**振り返りのページの状態と表示**

| 状態                                    | 表示                                                                        | 対象の AC |
| --------------------------------------- | --------------------------------------------------------------------------- | --------- |
| 読み込み中（サーバーでの描画時）        | 上の帯だけ                                                                  |           |
| 保存データが壊れている                  | 「データを読み込めなかったみたい…」と「ホームへ」（やり直しはホームで行う） |           |
| キャラクターがいない                    | 🐣・「ホームで名前を付けてね」・「ホームへ」                                | AC-5      |
| キャラクターはいるが、日記が 1 件もない | 🐣・「まだ日記がないよ。ホームで今日の日記を書いてみよう」・「ホームへ」    | AC-4      |
| 日記がある                              | 見出し「ふりかえり」・案内の文・一覧                                        | AC-2, 3   |

- 上の帯は、左に「‹ ホーム」（`/` へのリンク）、真ん中に「logling」。ページの見出し（`h1`）は「ふりかえり」

**一覧（`buildHistory` の結果を並べる）**

| 項目                          | 表示（この Bolt）                                                                       | ボタン（あとの Bolt）            |
| ----------------------------- | --------------------------------------------------------------------------------------- | -------------------------------- |
| 最近 7 日の日記               | 短い日付・「あとから」の印（後から書いた日記だけ）・本文（改行もそのまま）              | 「書き直す」「消す」（Bolt-3）   |
| 空いた日（今日より前の 6 日） | 点線のカード・短い日付・「この日はまだ書いていないよ（あとから書くと +5 経験値）」      | 「この日の日記を書く」（Bolt-4） |
| 8 日以上前の日記              | 区切りの文「― ここから下は 8 日以上前の日記（読むだけ） ―」のあとに、短い日付・印・本文 | なし                             |

- 案内の文「最近 7 日の日記は、書き直したり消したりできるよ」の「7」と、空いた日の「+5」は、定数（`RECENT_DAYS`・`EXP_PER_LATE_ENTRY`）から作る
- 一覧は、見出し付きのリスト（`<ul>`・`<li>`）にし、読み上げ機能でも 1 日ずつ区切って読めるようにする
- 8 日以上前の日記がないときは、区切りの文も出さない

**⑥ で書くテスト（例）**

- `formatShortDiaryDate`：`2026-11-07` → `11月7日（土）`
- `HistoryList`：並び順・「あとから」の印・空いた日の文言・区切りの文が 8 日以上前の日記の前に出る・8 日以上前がなければ区切りは出ない・本文の改行
- `HistoryPage`：キャラクターがいない → 名前の案内（AC-5）／日記がない → 日記がない案内（AC-4）／日記がある → 見出しと一覧（AC-2）／開き直しても同じ表示（AC-20）／「ホーム」へのリンクがある（AC-1）
- `Home`：キャラクターがいるときは「ふりかえる」のリンクがある・名前を付ける前はない（AC-1）

**ADR**

この Bolt でも ADR は作らない。
