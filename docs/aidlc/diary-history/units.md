# Units：日記の振り返り（diary-history）

## 全体像

```
U-1 振り返り（src/features/history/）
 ├─ 使う：U-1 キャラクター（diary-exp。経験値とレベルの計算）
 ├─ 使う：U-2 日記（diary-exp。日記の型・本文の検証・入力欄）
 └─ 使う：U-3 ホーム画面（diary-exp。保存データの読み書き）
```

- 新しく作る Unit は「振り返り」の 1 つ。振り返りのページのロジックと画面を受け持つ
- `diary-exp` で作った Unit にも、次の変更を加える（どの Bolt で変えるかは Bolt 計画に書く）
  - 日記（`src/features/diary/`）：日記ごとに「その日に書いたか、後から書いたか」を持たせる。入力欄の呼びかけの文言を、書き直し・後から書くときにも使えるようにする
  - キャラクター（`src/features/character/`）：後から書いた日記の経験値（5）を加える。経験値を減らす計算を加える
  - ホーム画面（`src/features/home/`）：「ふりかえる」のリンクを置く。保存データの読み込みで、これまでの日記（書き方の記録がない日記）を受け入れる

## U-1：振り返り（`src/features/history/`）

- 含む Story：S-1, S-2, S-3, S-4, S-5, S-6, S-7
- 依存：`diary-exp` のキャラクター・日記・ホーム画面
- 受け持つこと：一覧の組み立て（新しい順、最近の空いた日を含む）、書き直し・削除・後から書けるかの判定（最近 7 日）、書き直し・削除・後から書いたときの保存データと経験値の計算、振り返りのページの画面、`src/app/history/page.tsx` からの呼び出し

### Bolt 計画

- Bolt-1：データの形と計算。日記の書き方の記録・後から書いた日記の経験値・これまでの日記の扱い・「最近 7 日」の判定・一覧の組み立て・書き直し／削除／後から書いたときの計算（ロジックのみ。AC-7, AC-10〜AC-12 の計算, AC-15 の計算, AC-18, AC-19, AC-21）
- Bolt-2：振り返りのページ（読むだけ）とホームからのリンク（AC-1〜AC-5, AC-20 の読み込み）
- Bolt-3：書き直しと削除（画面と保存）（AC-6〜AC-13, AC-20, AC-22）
- Bolt-4：後から書く（画面と保存）と、始めた日の記録（AC-14〜AC-17, AC-20, AC-22, AC-24）
- Bolt-5：スマホ幅での表示と、振り返りの一連の操作の E2E テスト（AC-23）

### 設計（⑤で追記）

#### Bolt-1：データの形と計算

**日記のデータの形（`src/features/diary/diary.ts` を変える）**

```ts
type DiaryEntry = {
  date: string; // 日記の日付（朝 4 時区切り）
  body: string;
  createdAt: string; // 保存した時刻
  writtenLater?: true; // 後から書いた日記だけに付ける。ない日記は「その日に書いた日記」
};
```

- 「後から書いた」ときだけ `writtenLater: true` を付け、それ以外は何も付けない
  - 理由：`diary-exp` で保存した日記には、この印がない。印がなければ「その日に書いた日記」と読めば、これまでのデータを書き換えずにそのまま使える（AC-21）
- 保存データの読み込み（`src/features/home/save-data.ts`）では、`writtenLater` が「ない」か「`true`」のときだけ正しい形として受け入れる。それ以外（例：`false` や文字列）は壊れたデータとして扱う
- `entries` は、これまでどおり日付の古い順に並べる。後から書いた日記は、日付の順の正しい位置に入れる

**経験値のきまり（`src/features/character/character.ts` に加える）**

| 項目               | 値・関数                                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------------------- |
| その日に書いた日記 | 10（今の `EXP_PER_ENTRY`）                                                                                 |
| 後から書いた日記   | 5（`EXP_PER_LATE_ENTRY` を新しく加える）                                                                   |
| 経験値を減らす     | `loseExp(character, amount)`：合計から減らし（0 より下にはしない）、減らす前と後のレベル・下がったかを返す |

- 日記 1 件ぶんの経験値（10 か 5）を求める `expForEntry(entry)` は、日記とキャラクターの両方を知っている振り返りの Unit に置く

**「最近 7 日」の判定（`src/lib/diary-date.ts` に加える。`streak` でも使う）**

| 関数                             | 内容                                                                                    |
| -------------------------------- | --------------------------------------------------------------------------------------- |
| `addDays(date, days)`            | 日記の日付に日数を足す・引く（例：`2026-11-01` に -1 → `2026-10-31`）。月・年をまたげる |
| `isRecentDiaryDate(date, today)` | 今日を含めた最近 7 日（今日〜6 日前）に入るか                                           |

- `RECENT_DAYS = 7` を定数にし、文言（「最近 7 日」）も同じ定数から作る

**振り返りのロジック（`src/features/history/history.ts`。新しく作る）**

| 関数                                            | 内容                                                                                                                                                                  | 対象の AC           |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- |
| `buildHistory(entries, today)`                  | 一覧に並べる項目を、日付の新しい順に返す。最近 7 日は、日記があれば「書き直し・削除できる日記」、今日以外で日記がなければ「空いた日」。それより前は「読むだけの日記」 | AC-2, 3, 14, 18, 19 |
| `expForEntry(entry)`                            | 日記 1 件ぶんの経験値（後から書いた日記は 5、それ以外は 10）                                                                                                          | AC-10, 21           |
| `previewDelete(data, date)`                     | 消したら減る経験値と、消す前・後のレベルを返す（確認の文言に使う。保存はしない）                                                                                      | AC-10, 11           |
| `editEntry(data, date, body, today)`            | 最近 7 日の日記の本文を差し替えた保存データを返す。経験値は変えない                                                                                                   | AC-7                |
| `deleteEntry(data, date, today)`                | 最近 7 日の日記を消し、その日記ぶんの経験値を減らした保存データと、レベルが下がったかを返す                                                                           | AC-12               |
| `writeLaterEntry(data, date, body, today, now)` | 今日より前の最近 6 日で、日記がない日に、後から書いた日記を加え、経験値を 5 足した保存データと、レベルが上がったかを返す                                              | AC-15               |

- どの関数も、元の保存データは書き換えず、新しい保存データを返す（`diary-exp` と同じ作り）
- 最近 7 日の外の日付・すでに日記がある日・今日の日付への後から書く、など、できない操作のときは「失敗」を返し、保存データは変えない（画面でボタンを出さないことに加えて、ロジックの側でも守る）
- 本文の検証は、これまでどおり画面の部品（入力欄）で `validateBody` を使って行う。ここに渡すのは検証済みの本文

```
src/features/character/character.ts / .test.ts     # EXP_PER_LATE_ENTRY・loseExp を加える
```

**⑥ で書くテスト（例）**

- `addDays`：月末（11/1 → 10/31）・年末（1/1 → 12/31）・足す方向
- `isRecentDiaryDate`：今日が 11/7 なら、11/1〜11/7 は入る、10/31 は入らない
- `loseExp`：合計 75（Lv3）から 10 減らす → 65（Lv2、下がった）／合計 5 から 10 減らす → 0 で止まる
- `buildHistory`：今日 11/7 で、11/7・11/5（後から）・10/31 に日記、11/6 などが空いている例で、並び順と項目の種類
- `expForEntry`：印なし（これまでの日記）→ 10、後から → 5
- `previewDelete`・`deleteEntry`：減る量・レベルの変化・一覧から消えること・範囲外の日付は失敗
- `editEntry`：本文が変わり、経験値は同じ・範囲外は失敗
- `writeLaterEntry`：日付の順の位置に入る・5 足される・レベルアップ・今日・日記がある日・範囲外は失敗
- `save-data`：`writtenLater: true` の日記は読める・印のない日記もそのまま読める・`writtenLater: false` は壊れたデータ

#### Bolt-3：書き直しと削除

**ファイル**


- 文言の移動（`SaveErrorNotice`・`bodyErrorMessage`）は、ホームの表示を変えない作り直し（リファクタリング）。ホームのテストがそのまま通ることで確かめる

**状態の置き場所**

| 状態                                 | 置き場所      | 理由                                                          |
| ------------------------------------ | ------------- | ------------------------------------------------------------- |
| どのカードを書き直し中か（日付）     | `HistoryList` | 一覧の中だけで使う見た目の状態。同時に書き直せるのは 1 枚だけ |
| 入力中の本文・エラー                 | `EntryForm`   | 入力欄の中だけで使う                                          |
| どの日記を消そうとしているか（日付） | `HistoryPage` | 確認の窓を出し、保存データを書き換えるのはページの役目        |
| 保存できなかったこと                 | `HistoryPage` | ホームと同じく、ページの上にまとめて出す                      |

- `HistoryList` には、`onSaveEdit(date, body)`（保存できたら `true` を返す）と `onRequestDelete(date)` を渡す
- 書き直し中は、ほかのカードの「書き直す」「消す」を出さない（入力中の文章を、ほかのボタンを押して失わないようにするため）

**書き直す（AC-6〜9）**

1. 「書き直す」を押すと、カードの中が `EntryForm` に変わる。入力欄には今の本文が入り、文字数（「22 / 2000」）が出る。入力欄にフォーカスを移す
2. 「保存する」：本文のきまりは `diary-exp` と同じ `validateBody`。空・2001 文字以上なら、`diary-exp` と同じ文言のエラーを出して保存しない（AC-8）
3. 保存するときは「今日」をその場で計算し直し（ホームと同じ。4 時をまたいで開きっぱなしの場合に備える）、`editEntry` で書き換えて保存する。経験値とレベルは変わらない（AC-7）。お知らせ（トースト）は出さない（モックの判断どおり）
4. 保存できたら入力欄を閉じ、カードに新しい本文を表示する
5. 「やめる」：入力欄を閉じ、本文は元のまま（AC-9）

**消す（AC-10〜13）**

1. 「消す」を押すと、`previewDelete` で減る経験値と、消した後のレベルを計算し、`DeleteDialog` を出す（何も保存しない）
2. 確認の窓の文言（モックどおり）
   - 「11月7日の日記を消す？」
   - 「消すと経験値が 10 減るよ。」（後から書いた日記は 5）（AC-10）
   - レベルが下がるときだけ「ぴよ のレベルが 3 から 2 に下がるよ。」を注意の色で（AC-11）
   - 「消した日記は元に戻せないよ」
   - ボタン「消す」（注意の色）・「やめる」
3. 窓を開いたときは「やめる」にフォーカスを置く（うっかり Enter で消さないようにするため）。Esc キーでも「やめる」と同じになる
4. 「消す」：「今日」を計算し直し、`deleteEntry` で日記を消して経験値を減らし、保存する。窓を閉じる。消した日が最近 7 日（今日を除く）なら、その日は空いた日のカードに変わる（AC-12）
5. 「やめる」：窓を閉じ、何も変わらない（AC-12）
6. 今日の日記を消すと、ホームでは今日の日記がない状態に戻り、入力欄が出る（AC-13。ホームは今の作りのままで、そうなる）

**うまくいかないとき**

| 場面                                                | 動き                                                                                                     |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 保存に失敗した（書き直し）                          | 「保存できなかった…」をページの上に出す。入力欄は開いたまま、書いた文章も残す。日記は変わらない（AC-22） |
| 保存に失敗した（削除）                              | 窓を閉じ、「保存できなかった…」を出す。日記と経験値は変わらない（AC-22）                                 |
| 開きっぱなしの間に 4 時をまたぎ、8 日以上前になった | 保存せず、「この日記は、もう書き直したり消したりできないよ」を出す                                       |

- 最後の行は AC にない動き。めったに起きないが、「古い日記は読むだけ」（S-5）を守るために入れる。⑧ で「仕様にない実装」として確認する

**⑥ で書くテスト（例）**

- `formatMonthDay`：`2026-11-07` → `11月7日`
- `EntryForm`：今の本文が入っている（AC-6）／空や 2001 文字以上では保存されず、エラーが出る（AC-8）／「やめる」で閉じる（AC-9）
- `DeleteDialog`：減る経験値（AC-10）／レベルが下がるときだけ下がる文が出る（AC-11）／「やめる」にフォーカスがある／「消す」「やめる」でそれぞれの処理が呼ばれる
- `HistoryList`：最近 7 日の日記にだけ「書き直す」「消す」がある（AC-6, 10, 18）／書き直し中は、ほかのカードのボタンが出ない。Bolt-2 のテストは、2 つの処理を渡す形に直す
- `HistoryPage`：書き直して保存すると一覧と保存データが変わり、経験値は変わらない（AC-7, 20）／消すと一覧から消えて経験値が減る・やめると変わらない（AC-12, 20）／書き方の記録がない日記は 10 減る（AC-21）／保存に失敗すると、日記も経験値も変わらない（AC-22）／今日の日記を消したあと、ホームに入力欄が出る（AC-13）

**ADR**

- お知らせは、`diary-exp` の `ExpGainToast`（「✨ +5 経験値！」）と `LevelUpDialog` をそのまま使う（AC-16）

**始めた日（AC-14, AC-24）**

保存データの形の変更（`version` は 1 のまま。記録がなくても読めるため）：

```ts
type Character = {
  name: string;
  totalExp: number;
  /** 名前を付けた日（朝 4 時で区切った日付）。diary-exp で名前を付けたデータにはない */
  startDate?: string;
};
```

- 名前を付けるときは、その場で `getDiaryDate(new Date())` を計算し、始めた日として保存する。日記を書いていなくても、その日が始めた日になる
- `getStartDate(data)`：`startDate` があればそれを使う。なければ一番古い日記の日を使う（AC-24）。日記もなければ `null`（この場合は振り返りのページが「まだ日記がないよ」の案内になるので、一覧は出ない）
- `buildHistory(entries, today, startDate)`：空いた日は、始めた日以降の日だけにする。始めた日より前の日は、カードも出さない（AC-14）
- `writeLaterEntry`：始めた日より前の日なら保存しない（画面を通さずに呼ばれたときの守り）
- （⑥ で追加）始めた日の記録がないデータは、`editEntry`・`deleteEntry`・`writeLaterEntry` で保存するときに、その時点の始めた日（一番古い日記の日）を `startDate` として書き込む。一番古い日記を消したときに、始めた日が後ろにずれないようにするため
- Bolt-1 の `buildHistory` のテストは、始めた日を渡す形に直す。`createCharacter` の `diary-exp` のテストも、始めた日を渡す形に直す

**状態の置き場所**

- Bolt-3 の「どのカードを書き直し中か」を、「どのカードで入力中か」に広げる。書き直し中も後から書く途中も、入力できるのは 1 枚だけで、その間はほかのカードのボタンを出さない
- `HistoryList` には `onSaveLater(date, body)`（保存できたら `true` を返す）を加えて渡す
- 経験値のお知らせ（増えた量）とレベルアップ（新しいレベル）は `HistoryPage` が持つ（ホームと同じ持ち方）

**後から書く（AC-14〜17）**

1. 空いた日のカードの「この日の日記を書く」を押すと、カードの中が `EntryForm` に変わる（AC-14）
   - 問いかけ：🐣「11月6日は、どんな一日だった？」
   - 入力欄の案内：「思い出せることを書いてみよう」
   - 入力欄は空で始まり、フォーカスを移す。ボタンは「日記をのこす」「やめる」
2. 「日記をのこす」：本文のきまりは `diary-exp` と同じ `validateBody`（AC-17）
3. 保存するときは「今日」をその場で計算し直し、`writeLaterEntry` で日記を加え、経験値を 5 足して保存する（AC-15）
4. 保存できたら入力欄を閉じる。カードは「あとから」の印の付いた日記のカードに変わり、そのまま「書き直す」「消す」もできる
5. 「✨ +5 経験値！」を出す。レベルが上がったときは、レベルアップのお知らせも出す（AC-16）
6. 「やめる」：入力欄を閉じ、何も変わらない

**うまくいかないとき**

| 場面                                                         | 動き                                                                                                 |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| 保存に失敗した                                               | 「保存できなかった…」を出す。入力欄は開いたまま、書いた文章も残す。日記と経験値は変わらない（AC-22） |
| 開きっぱなしの間に 4 時をまたぎ、その日が 8 日以上前になった | 保存せず入力欄を閉じ、「この日には、もう後から書けないよ」を出す（Bolt-3 と同じ考え方）              |

- 最後の行は、Bolt-3 と同じく AC にない動き。⑧ で「仕様にない実装」として確認する

**⑥ で書くテスト（例）**

- `character`・`save-data`：`createCharacter` が始めた日を持つ／始めた日がないデータも、正しい形の始めた日があるデータも読める／形のおかしい始めた日は壊れたデータになる（AC-24）
- `history`：`getStartDate` は記録があればそれ、なければ一番古い日記の日（AC-24）／`buildHistory` は始めた日より前の空いた日を出さない（AC-14）／`writeLaterEntry` は始めた日より前に書けない（AC-14）
- `Home`：名前を付けると、その日が始めた日として保存される。朝 4 時前なら前の日になる（AC-24）
- `EntryForm`：問いかけと入力欄の案内を渡すと表示される
- `HistoryList`：空いた日のカードにだけ「この日の日記を書く」がある（AC-14）／押すと、問いかけと空の入力欄が出る／保存すると日付と本文が渡される／入力中は、ほかのカードのボタンが出ない
- `HistoryPage`：後から書くと「あとから」の印付きで一覧に入り、保存データに印と +5 の経験値が残る（AC-15, 20）／「+5 経験値！」が出る（AC-15）／必要な経験値に達するとレベルアップのお知らせが出る（AC-16）／空や 2001 文字以上は保存されない（AC-17）／保存に失敗すると何も変わらない（AC-22）／4 時をまたいだとき

**ADR**

この Bolt でも ADR は作らない（新しい技術の選定はない）。

#### Bolt-5：スマホ幅での表示と E2E テスト

**ファイル**

```
e2e/diary-history.spec.ts    # 振り返りの一連の操作を、幅 375px の本物のブラウザ（Chromium）で確かめる
```

- 画面の作りは Bolt-2〜4 で幅 480px までの 1 列にしてあり、長い本文も折り返す（`break-words`）。この Bolt では E2E テストで確かめ、崩れが見つかったときだけ直す

**日付の固定**

- 「最近 7 日」や空いた日は今日の日付で変わるため、Playwright の `page.clock.setFixedTime` で、ブラウザの中の時刻を「2026 年 11 月 7 日 21 時」に固定する。時刻だけを固定し、お知らせを消すタイマーなどはふつうに動く
- 保存データは、`diary-exp` の E2E テストと同じく、ページを開いてから localStorage に入れて読み込み直す。始めた日は 11 月 1 日、日記は 11 月 7 日（今日）・5 日（後から書いた）・10 月 25 日（読むだけ）とする

**確かめること（AC-23 と、単体テストでは確かめにくいこと）**

| テスト                                                                                                                   | 対象の AC |
| ------------------------------------------------------------------------------------------------------------------------ | --------- |
| ホームの「ふりかえる」から振り返りに移り、一覧が出て、「ホーム」で戻れる。タブのタイトルは「ふりかえり \| logling」      | AC-1, 2   |
| 書き直して保存すると本文が変わり、再読み込みしても残る                                                                   | AC-7, 20  |
| 消す前の確認では「やめる」にフォーカスがあり、Esc キーで閉じると何も変わらない。「消す」で消すと空いた日のカードに変わる | AC-10〜12 |
| 後から書くと「✨ +5 経験値！」が出て、「あとから」の印が付き、再読み込みしても残る                                       | AC-15, 20 |
| 長い本文（英字だけの長い文字列を含む）の表示中・書き直し中・後から書く途中、確認の窓を開いた状態で、横スクロールが出ない | AC-23     |
| 振り返りの操作（書き直す・消す・後から書く）の間、同じオリジン以外へ通信せず、本文も送らない                             | AC-20     |

- 確認の窓の「やめる」へのフォーカスと Esc キーは、jsdom では確かめられなかったため、ここで確かめる（Bolt-3 で決めたとおり）
- 公開中のサイトに対しても、`BASE_URL` を指定すれば同じテストを実行できる（`release` で作ったしくみ）

**ADR**

この Bolt でも ADR は作らない。
