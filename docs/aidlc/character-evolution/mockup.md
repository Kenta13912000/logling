## 方針

| 項目                 | 内容                                                                                                                                                                                                                                                                      |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ステータス           | 🐣 を今の段階の絵（64px）に置き換える。ステータスの区画は上下の余白を少し詰め、日記の入力欄を縦に広げる（高さ 200px）。絵の周りの余白は段階ごとに切り取り、キャラクターを枠いっぱいに出す（レイアウトは変えずに大きく見せるため）。名前の横に、段階の名前を小さな枠で出す |
| 吹き出しの横         | 🐣 を今の段階の絵（48px）に置き換える。ステータスと同じく余白を切り取る。飾りなので読み上げない                                                                                                                                                                           |
| 名前を付ける前       | 段階 1 の絵を大きく（220px）出す。吹き出しの横の絵はなくす（上の絵と重なるため）                                                                                                                                                                                          |
| すがたが変わったとき | いつものレベルアップのお知らせ（🎉）の代わりに、新しい段階の絵（240px）と「<名前> が <段階の名前> になった！」                                                                                                                                                            |
| レベルが下がったとき | 消す前の確認で、段階が戻るときだけ「すがたも前にもどるよ。」を注意の色で足す                                                                                                                                                                                              |
| ファビコン           | 段階 1 の絵をそのまま使う                                                                                                                                                                                                                                                 |

## 画面と文言

| 画面                        | 対象の AC   | 主な文言                                                                                               |
| --------------------------- | ----------- | ------------------------------------------------------------------------------------------------------ |

- 同じ段階の中でレベルが上がったときは、これまでどおり「🎉 <名前> が レベル N になった！」のお知らせ（AC-7）
- 振り返りのページで後から書いて段階が変わったときも、画面 3 と同じお知らせ（AC-8）

## 判断メモ

- 絵の受け取り：開発者が描いた 5 枚の SVG を受け取り、中身を読んでスクリプトや外部の読み込みがないことを確かめた。段階 4・5 に入っていた文字は、どの端末でも同じ形になるよう、開発者が図形（アウトライン）にして置き直した
- 修正を依頼した点：どの画面もキャラクターを大きくした（ステータス 56→64px、吹き出し 32→48px、すがたが変わったお知らせ 160→240px、名前を付ける前 160→220px）。ステータスは枠の大きさを変えずにキャラクターを大きく見せるため、段階ごとに絵の余白を切り取る形にした。あわせてステータスの区画を少し低くし、日記の入力欄を広げた（120→200px）
- モックへのゲートでの判断：上記の修正を反映して承認（ファビコンは段階 1 の絵のまま。消す前の確認には絵を出さない）
