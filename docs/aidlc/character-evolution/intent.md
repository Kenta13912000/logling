# Intent：キャラクターの成長（character-evolution）

日記が続かない人が、書き続けてレベルが上がるにつれて、自分で名前を付けたキャラクターのすがたが変わっていくのを見て、「次のすがたも見たい」と思い、書き続ける理由を持てるようにする。

## 対象ユーザー

- 毎日日記を書きたいが、書くのを続けられない人（`diary-exp` と同じ）
- 数字（レベル・経験値）だけでなく、目に見える変化があると頑張れる人

## SC（成功条件）

- SC-1：ホームのキャラクターのステータスに、今のレベルに合った段階の絵と、その段階の名前が表示される。段階は 5 つで、レベル 1〜4・5〜9・10〜14・15〜19・20 以上で変わる
- SC-2：日記を書いて（後から書いた場合も）次の段階のレベルに上がると、いつものレベルアップのお知らせの代わりに、すがたが変わったことが新しい絵と一緒にわかるお知らせが出る
- SC-3：日記を消してレベルが下がり、前の段階のレベルに戻ったときは、絵も今のレベルの段階に戻る
- SC-4：ブラウザのタブのアイコン（ファビコン）が、段階 1 の絵をもとにしたアイコンになる（今の Next.js の初期のアイコンを置き換える）
- SC-5：ブラウザを開き直しても、今のレベルに合った段階の絵が表示される
- SC-6：スマホの画面幅（375px）で、絵とお知らせが横スクロールなしに表示される。絵はアプリの中のファイルで、外部から読み込まない

## 前提

- 絵は開発者が自分で描いたオリジナルの絵（SVG）を使う。既存のキャラクターをもとにした絵は使わない
- 5 枚の絵は同じ大きさの正方形で、背景は透明。組み込む前に中身を読み、スクリプトや外部への読み込みがないことを確かめる。画面では画像として表示する（中のプログラムが動かない形）
- 段階は、保存されている経験値の合計から決まるレベルだけで決める。新しく保存するものはない（そのため、レベルが下がれば段階も戻る）
- 毎日書いた場合のめやす（ボーナスを含む）：段階 2（レベル 5）まで約 2 週間、段階 3（レベル 10）まで約 2 か月、段階 4（レベル 15）まで約 3 か月半、段階 5（レベル 20）まで約 5〜6 か月
- レベルの上限はないので、レベル 20 より先は段階 5 のまま
- 5 つの段階には名前を付ける（例：「ぴよ が ○○ になった！」）。名前は、開発者が絵を渡すときに決める

## スコープ外

| 内容                                    | 扱い                                   |
| --------------------------------------- | -------------------------------------- |
| 絵が動く（アニメーション）              | 扱わない                               |
| 見た目を選ぶ・着せ替え                  | 扱わない                               |
| 連続日数による見た目の変化              | 扱わない（見た目はレベルだけで決める） |
| スマホのホーム画面に置くアイコン（PWA） | `pwa-reminder`                         |
| 段階 5 より先の見た目                   | 必要になったら検討                     |

## 判断メモ

- 作成前に確認した点：見た目は開発者が描くオリジナルの絵／見た目が変わるときはレベルアップのお知らせで知らせる／日記を消してレベルが下がったら見た目も戻す／ファビコンは段階 1 の絵で固定
- 修正を依頼した点：段階は当初 4 段階（レベル 1・5・10・20）で決めたが、絵を描く中で 5 段階に変え、レベル 1・5・10・15・20 にした（前の区切りを活かし、10 と 20 の間に 15 を足すため）
- 絵の形式：線や図形で描いているため SVG にした（拡大してもぼやけず、ファイルが小さいため）
- 既存のキャラクターを AI で改変した絵は使わない（著作権のおそれと、公開のポートフォリオであることから）
- Intent へのゲートでの判断：指摘なしで承認（新しく保存するものはない。後から書いた日記で段階が上がった場合も知らせる。レベル 20 より先は段階 5 のまま）
- ② Stories のゲートで変更：段階に名前を付け、ステータスとすがたが変わったお知らせに出すことにした（SC-1 と前提に追記）
