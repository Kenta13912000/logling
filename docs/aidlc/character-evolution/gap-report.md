# 差分レポート：キャラクターの成長（character-evolution）

実装から書き起こした [要件定義書](../../requirements/character-evolution.md) と、当初の [intent.md](intent.md)・[stories.md](stories.md)・[mockup.md](mockup.md) を比べた結果。

## 未実装の AC

なし。AC-1〜AC-16 はすべて実装され、テストで確かめている。AC-9（一度に 2 つ以上上がって段階が変わる）は、今の経験値のきまりでは画面で起きないため、段階の判定の単体テストで確かめている。

## 判断メモ

- A は、これまでの機能の ⑧ と同じく、テストのある動きを AC にした。テストはすでにあったので、テストの名前に AC-17 を付けた
- C・D・E は、ゲートでの開発者の指摘や受け取ったときの確認で決めたことのため、要件定義書への記録だけにした
- H は、PNG のアイコンがスマホのホーム画面のアイコンと作り方が近いため、`pwa-reminder` で一緒に作ることにし、ロードマップに書いた
- I は、公開中のサイトへの確認がマージとデプロイのあとでないとできないため、PR のマージ後の後片付けと一緒に実行する
- 差分レポートへのゲートでの判断：提案どおりの対応で、指摘なしで承認
