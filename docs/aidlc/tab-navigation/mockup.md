# UI モック：下のタブで画面を切り替える（tab-navigation）

見た目は [mockup.html](mockup.html) で確認する（ファイルをブラウザで開くだけ。外部への通信はしない）。色・フォント・ボタンの大きさは `diary-exp` の [mockup.md](../diary-exp/mockup.md) と同じ。

## 方針

| 項目           | 内容                                                                                                                                                             |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 上の帯         | 「logling」を真ん中に置くだけ。リンクはない                                                                                                                      |
| 下のタブ       | 白い帯に 3 つ。上にアイコン、下に短い名前（11px）。1 つの高さは 56px。iPhone の画面の下の線の分の余白を足す                                                      |
| アイコン       | 線で描いたかんたんな形：ホームは家、ふりかえるは開いた本、その他は点 3 つ。logling のために描く                                                                  |
| 今いるタブ     | アイコンと名前がオレンジ色（ボタンと同じ色）、アイコンの中を薄いオレンジで塗る。それ以外は茶色がかった灰色                                                       |
| その他         | 白いカードに 3 行：「アカウント」（下にログイン中のメールアドレス、または「ログインしていない」）・「日記の保存のしかた」・「設定」。行の左にアイコン、右に「›」 |
| 設定           | 「設定は、これから増えるよ」と「たとえば、日記を書く時間のお知らせなど」                                                                                         |
| 文字を打つとき | 入力欄が選ばれている間はタブを隠す                                                                                                                               |
| お知らせ       | 経験値などのお知らせは、タブの上に出す（今は画面の下の方に出ているので、タブの高さの分だけ上げる）                                                               |
| 確認の窓       | 消す・退会・引き継ぎ・レベルアップの確認は、タブより手前に出す（タブも暗くなる）                                                                                 |

## 画面と文言

| 画面                  | 対象の AC        | 主な文言                                                                              |
| --------------------- | ---------------- | ------------------------------------------------------------------------------------- |
| 1. ホーム             | AC-1, AC-3, AC-8 | 上の帯「logling」、タブ「ホーム」「ふりかえる」「その他」                             |
| 2. 文字を打っている間 | AC-9             | タブは出ない                                                                          |
| 3. ふりかえり         | AC-3, AC-8       | 「‹ ホーム」はなくなる                                                                |
| 4. その他             | AC-5, AC-6       | 「その他」「アカウント」「ログイン中：you@example.com」「日記の保存のしかた」「設定」 |
| 5. 設定               | AC-3, AC-7       | 「設定」「設定は、これから増えるよ」「たとえば、日記を書く時間のお知らせなど」        |
| 6. ホームのいちばん下 | AC-10            | フッターがタブの上に見える                                                            |
| 7. お知らせ           | AC-11            | 「✨ +10 経験値！」がタブの上                                                         |
| 8. 確認の窓           | AC-11            | 確認の窓がタブより手前                                                                |

- アカウントの画面と日記の保存のしかたの画面も、上の帯は「logling」だけになり、「その他」が今のタブになる
- 名前を付ける前の画面にもタブが出る。「ほかの端末で使っていた人は ログイン ›」は残す

## 判断メモ

- モックへのゲートでの判断：指摘なしで承認（アイコンは家・開いた本・点 3 つ、今いるタブはオレンジ色、設定の画面の例はこれから作る書く時間のお知らせ、タブの高さは 56px ＋ iPhone の画面の下の線の分）
