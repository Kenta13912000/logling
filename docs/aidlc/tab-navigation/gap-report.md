## 判断メモ

- A〜E は、テストのある動きで、作っている途中のゲートで決めたことのため、新しい AC は作らず、AC-3・AC-6・AC-8・AC-9 の文に書き足した
- F・H は、不具合の直しと細かい寸法のため、要件定義書への記録だけにした
- G は、見本の説明が実際と違っていたため、mockup.md の説明を直した（mockup.html の絵はそのまま）
- I は、この機能の完了に合わせて、`diary-exp`・`diary-history`・`account-sync` の要件定義書、README、ロードマップを更新した
- J・K は、取り込んでデプロイしたあとでないとできないため次回へ回し、取り込んだあとの作業として行う
- 差分レポートへのゲートでの判断：提案どおりの対応で承認
- K の実行結果：公開中のサイトで 1 件がテストの書き方の問題で失敗したため、軽い手順（`fix/tab-navigation-e2e-wait`）で E2E テストだけを直した。アプリのコードは変えていない
- J の実行結果：開発者の iPhone で、今いるタブの色、入力中にタブが隠れること、画面の下の線との重なりを確かめ、問題がなかった
- 軽い手順のゲート 3 での判断：E2E の直しと記録を、iPhone での確かめの結果とあわせて承認
