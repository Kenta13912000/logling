# Units：ホーム画面に追加と、書き忘れを防ぐお知らせ（pwa-reminder）

## U-1：ホーム画面に追加（`src/features/pwa/`）

- 含む Story：S-1, S-2
- 依存：
  - `src/app/`（アプリの名前・アイコン・開き方を書いたファイル（マニフェスト）と、アイコンの画像）
  - `src/features/navigation/`（ホーム画面から開いたときに、上の帯を画面の上の切り欠きにかぶらないようにする。「設定」の画面に項目を置く）

アプリの名前・アイコン・開き方と、追加の方法の案内。お知らせがなくても、これだけで使える。

### Bolt 計画

- Bolt-1：マニフェスト、PNG のアイコン（ホーム画面用・iPhone 用・Safari のファビコン用）、ホーム画面から開いたときの画面の上下の余白（AC-1〜AC-3）
- Bolt-2：「設定」の画面を項目が並ぶ形にし、「ホーム画面に追加」の項目と手順を置く。ホーム画面から開いているかどうかを見分ける（AC-4, AC-5, AC-21 の「設定」の部分）

## U-2：書き忘れを防ぐお知らせ（`src/features/reminder/`）

- 含む Story：S-3〜S-7
- 依存：
  - U-1（iPhone では、ホーム画面に追加していないとお知らせを受け取れない。「設定」の画面の形）
  - `src/lib/db/`（端末への宛先と時刻の表を足す）
  - `src/features/cloud/`（その日に書いたかどうかを、ログインしている人のデータで確かめる）
  - `src/features/account/`（ログアウト・退会のときに宛先を消す）
  - `src/features/privacy/`（説明ページに「お知らせ」の節を足す）

お知らせを受け取る準備（許可・宛先の保存）、送る時刻か確かめて送るしくみ、止めるしくみ。

### Bolt 計画

- Bolt-3：宛先と時刻を保存する表と、保存・変更・削除のサーバーの処理。ログアウト・退会のときに消す（AC-8, AC-10 のサーバーの部分, AC-15, AC-16）
- Bolt-4：「設定」の「お知らせ」の項目（オン・オフ・時刻・使えない理由）と、お知らせを受け取って表示し、押すとホームを開くしくみ（Service Worker）（AC-6, AC-7, AC-9, AC-10, AC-14, AC-20）
- Bolt-5：定期的に「送る時刻か」を確かめ、まだ書いていない人の端末に送る。1 日 1 回まで。使えなくなった宛先を消す（AC-11〜AC-13, AC-17）
- Bolt-6：説明ページの「お知らせ」の節。ログインしていない人のブラウザから外へ送らないことと、幅 375px の E2E（AC-18, AC-19, AC-21）

### テストの方針

- 送る時刻か・書いたかどうか・1 日 1 回までの判断は、画面や通信に依存しない関数にして、単体テストで細かく確かめる
- お知らせを実際に届ける部分は、テストでは「送ったつもりになる」偽物に差しかえる。テスト用のブラウザ（Chromium）では、Apple や Google のお知らせのしくみに本当には届けられないため
- 本物の iPhone と Android で届くことは、取り込んでデプロイしたあとに、開発者が自分の端末で確かめる

### 設計（⑤で追記）

#### Bolt-1：マニフェスト・PNG のアイコン・画面の上下の余白

**アプリの名前・開き方（マニフェスト）**

- Next.js の決まった置き場所 `src/app/manifest.ts` に書く。Next.js が `/manifest.webmanifest` として配り、どのページにも `<link rel="manifest">` を入れる

| 項目                 | 値                                                                  |
| -------------------- | ------------------------------------------------------------------- |
| 名前・短い名前       | logling                                                             |
| 説明                 | 日記を書くとキャラクターが育つ、続けたくなる日記アプリ（今と同じ）  |
| 始まりのページ・範囲 | `/`                                                                 |
| 開き方               | `standalone`（アドレス欄のない画面）                                |
| 背景の色・テーマの色 | `#fff8ec`（クリーム色。起動したときの画面と、Android の上の帯の色） |
| 言語                 | `ja`                                                                |
| アイコン             | 192px・512px（ふつう）、512px（切り抜かれる用：`maskable`）         |

- iPhone 向けに、ページの設定に「ホーム画面から開けるアプリ」であることと、名前「logling」を足す（`appleWebApp`）。画面の上の時計や電池の表示は、ふつうの色（`default`）にする
- ページの設定の「テーマの色」も `#fff8ec` にする

**PNG のアイコン**

- もとの絵は、今のファビコン `src/app/icon.svg`（段階 1 の絵）。ここから PNG を作る小さなスクリプト `scripts/make-icons.mjs` を置き、`npm run icons` で作り直せるようにする。作った PNG はリポジトリに入れる（毎回のビルドでは作らない）
- PNG を作る道具は `sharp`。Next.js がすでに「入っていれば使う」部品として入れている 0.35.5 を、開発用の部品として明記する（版は同じ）

| ファイル                             | 大きさ | 使い道                                                        | 絵の大きさ（まわりはクリーム色）          |
| ------------------------------------ | ------ | ------------------------------------------------------------- | ----------------------------------------- |
| `public/icons/icon-192.png`          | 192px  | ホーム画面（Android など）                                    | 80%                                       |
| `public/icons/icon-512.png`          | 512px  | ホーム画面・起動したときの画面                                | 80%                                       |
| `public/icons/icon-maskable-512.png` | 512px  | 丸や角丸に切り抜かれるとき                                    | 60%（切り抜かれても欠けない真ん中の範囲） |
| `src/app/apple-icon.png`             | 180px  | iPhone のホーム画面（Next.js が自動で `apple-touch-icon` に） | 75%                                       |
| `src/app/icon1.png`                  | 32px   | Safari などのファビコン（SVG のファビコンと並べる）           | 絵だけ（背景なし）                        |

**画面の上下の余白**

- 上の帯（`AppHeader`）の上の余白に、画面の上の切り欠きの分（`env(safe-area-inset-top)`）を足す。ブラウザで開いているときは 0 なので、見た目は今と同じ
- 画面の下の余白は、`tab-navigation` で入れたもののまま

**ファイル**

```
src/app/manifest.ts / .test.ts            # マニフェスト
src/app/layout.tsx（変更）                 # appleWebApp・テーマの色
src/app/apple-icon.png・src/app/icon1.png # iPhone 用・PNG のファビコン
public/icons/icon-192.png・icon-512.png・icon-maskable-512.png
scripts/make-icons.mjs                     # icon.svg から PNG を作る（npm run icons）
src/features/pwa/icons.test.ts             # PNG の大きさと、切り抜かれる用の余白
src/features/navigation/AppHeader.tsx（変更） # 上の切り欠きの分の余白
e2e/pwa-reminder.spec.ts                   # ページにマニフェストと iPhone 用の設定があり、アイコンが届く
```

**テスト**

| テスト                                                                                                            | 種類 | AC         |
| ----------------------------------------------------------------------------------------------------------------- | ---- | ---------- |
| マニフェストの名前・開き方・始まりのページ・色・アイコン（大きさと切り抜かれる用）                                | 単体 | AC-1, AC-2 |
| PNG のアイコンが決まった大きさで、切り抜かれる用は四すみがクリーム色（絵が真ん中の範囲に収まっている）            | 単体 | AC-2       |
| ページに、マニフェストへのリンク・iPhone 用のアイコンと設定・PNG のファビコンがあり、マニフェストとアイコンが届く | E2E  | AC-1, AC-2 |

- 画面の上の切り欠き（AC-3）と、ホーム画面に追加して開いたときの見た目は、テスト用のブラウザでは再現できない。取り込んでデプロイしたあとに、開発者が自分の iPhone と（あれば）Android で確かめる

#### Bolt-2：「設定」の画面の形と、ホーム画面に追加の案内

**「設定」の画面の形**

- 見出し「設定」の下に、まとまりごとに小さな見出し（`<h2>`）と白いカードを並べる。この形を `SettingsSection` という部品にして、Bolt-4 の「お知らせ」でも使う
- PR-1 の時点では、まとまりは「ホーム画面に追加」の 1 つだけ。「お知らせ」は Bolt-4（PR-2）で、その上に足す（見本の並びどおり）
- 「設定は、これから増えるよ」「たとえば、日記を書く時間のお知らせなど」はなくす（`tab-navigation` AC-7 の文。AC-21 で直すと決めた部分）

**ホーム画面から開いているかの見分け方**（`display-mode.ts`。画面に依存しない関数）

- 次のどちらかなら「ホーム画面から開いている」
  - 画面の開き方が `standalone`（`matchMedia("(display-mode: standalone)")`。Android・PC・新しい iPhone）
  - iPhone の古いしくみの `navigator.standalone` が `true`
- サーバーで画面を作るときは、ブラウザのことがわからないので「ブラウザで開いている」として手順を出す。ブラウザで画面が動き出したら、すぐに見分け直す（`useSyncExternalStore`。Next.js の決まりで、サーバーとブラウザで最初の表示が食い違うとエラーになるのを避ける）

**ホーム画面に追加の案内**（`InstallGuide.tsx`）

| 状態                     | 出すもの                                                                                                  |
| ------------------------ | --------------------------------------------------------------------------------------------------------- |
| ブラウザで開いている     | 「ホーム画面に追加すると、アプリのように開けるよ」と、iPhone（Safari）・Android（Chrome）の番号付きの手順 |
| ホーム画面から開いている | 「✓ ホーム画面から開いているよ」だけ                                                                      |

- 手順の文は、見本（mockup.md の画面 3）どおり

**ファイル**

```
src/features/pwa/display-mode.ts / .test.ts          # ホーム画面から開いているかの見分け方
src/features/pwa/InstallGuide.tsx / .test.tsx        # ホーム画面に追加の案内
src/features/navigation/SettingsSection.tsx          # 「設定」のまとまり（小さな見出しと白いカード）
src/features/navigation/SettingsPage.tsx（変更）      # まとまりを並べる形に
src/features/navigation/SettingsPage.test.tsx（変更）
e2e/tab-navigation.spec.ts（変更）                   # 設定の画面で「これから増えるよ」を確かめていた 1 行を直す
e2e/pwa-reminder.spec.ts（追記）
```

**テスト**

| テスト                                                                                                              | 種類 | AC          |
| ------------------------------------------------------------------------------------------------------------------- | ---- | ----------- |
| 開き方が `standalone` か、`navigator.standalone` が `true` なら「ホーム画面から開いている」。どちらでもなければ違う | 単体 | AC-5        |
| ブラウザで開いているときは、iPhone と Android の手順が出る                                                          | 単体 | AC-4        |
| ホーム画面から開いているときは「✓ ホーム画面から開いているよ」だけで、手順は出ない                                  | 単体 | AC-5        |
| 「設定」に見出し「ホーム画面に追加」のまとまりがあり、「これから増えるよ」はない                                    | 単体 | AC-4, AC-21 |
| 「その他」→「設定」で、ホーム画面に追加の手順が見え、幅 375px で横スクロールが出ない                                | E2E  | AC-4, AC-21 |

- ホーム画面から開いたときの表示（AC-5）は、テスト用のブラウザでは再現できないので、単体テストと、取り込んだあとの開発者の端末で確かめる
