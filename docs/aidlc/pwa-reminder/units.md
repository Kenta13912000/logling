# Units：ホーム画面に追加と、書き忘れを防ぐお知らせ（pwa-reminder）

## U-1：ホーム画面に追加（`src/features/pwa/`）

- 含む Story：S-1, S-2
- 依存：
  - `src/app/`（アプリの名前・アイコン・開き方を書いたファイル（マニフェスト）と、アイコンの画像）
  - `src/features/navigation/`（ホーム画面から開いたときに、上の帯を画面の上の切り欠きにかぶらないようにする。「設定」の画面に項目を置く）

アプリの名前・アイコン・開き方と、追加の方法の案内。お知らせがなくても、これだけで使える。

### Bolt 計画

- Bolt-1：マニフェスト、PNG のアイコン（ホーム画面用・iPhone 用・Safari のファビコン用）、ホーム画面から開いたときの画面の上下の余白（AC-1〜AC-3）
- Bolt-2：「設定」の画面を項目が並ぶ形にし、「ホーム画面に追加」の項目と手順を置く。ホーム画面から開いているかどうかを見分ける（AC-4, AC-5, AC-21 の「設定」の部分）

## U-2：書き忘れを防ぐお知らせ（`src/features/reminder/`）

- 含む Story：S-3〜S-7
- 依存：
  - U-1（iPhone では、ホーム画面に追加していないとお知らせを受け取れない。「設定」の画面の形）
  - `src/lib/db/`（端末への宛先と時刻の表を足す）
  - `src/features/cloud/`（その日に書いたかどうかを、ログインしている人のデータで確かめる）
  - `src/features/account/`（ログアウト・退会のときに宛先を消す）
  - `src/features/privacy/`（説明ページに「お知らせ」の節を足す）

お知らせを受け取る準備（許可・宛先の保存）、送る時刻か確かめて送るしくみ、止めるしくみ。

### Bolt 計画

- Bolt-3：宛先と時刻を保存する表と、保存・変更・削除のサーバーの処理。ログアウト・退会のときに消す（AC-8, AC-10 のサーバーの部分, AC-15, AC-16）
- Bolt-4：「設定」の「お知らせ」の項目（オン・オフ・時刻・使えない理由）と、お知らせを受け取って表示し、押すとホームを開くしくみ（Service Worker）（AC-6, AC-7, AC-9, AC-10, AC-14, AC-20）
- Bolt-5：定期的に「送る時刻か」を確かめ、まだ書いていない人の端末に送る。1 日 1 回まで。使えなくなった宛先を消す（AC-11〜AC-13, AC-17）
- Bolt-6：説明ページの「お知らせ」の節。ログインしていない人のブラウザから外へ送らないことと、幅 375px の E2E（AC-18, AC-19, AC-21）

### テストの方針

- 送る時刻か・書いたかどうか・1 日 1 回までの判断は、画面や通信に依存しない関数にして、単体テストで細かく確かめる
- お知らせを実際に届ける部分は、テストでは「送ったつもりになる」偽物に差しかえる。テスト用のブラウザ（Chromium）では、Apple や Google のお知らせのしくみに本当には届けられないため
- 本物の iPhone と Android で届くことは、取り込んでデプロイしたあとに、開発者が自分の端末で確かめる
