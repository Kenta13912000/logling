# Units：ホーム画面に追加と、書き忘れを防ぐお知らせ（pwa-reminder）

## U-1：ホーム画面に追加（`src/features/pwa/`）

- 含む Story：S-1, S-2
- 依存：
  - `src/app/`（アプリの名前・アイコン・開き方を書いたファイル（マニフェスト）と、アイコンの画像）
  - `src/features/navigation/`（ホーム画面から開いたときに、上の帯を画面の上の切り欠きにかぶらないようにする。「設定」の画面に項目を置く）

アプリの名前・アイコン・開き方と、追加の方法の案内。お知らせがなくても、これだけで使える。

### Bolt 計画

- Bolt-1：マニフェスト、PNG のアイコン（ホーム画面用・iPhone 用・Safari のファビコン用）、ホーム画面から開いたときの画面の上下の余白（AC-1〜AC-3）
- Bolt-2：「設定」の画面を項目が並ぶ形にし、「ホーム画面に追加」の項目と手順を置く。ホーム画面から開いているかどうかを見分ける（AC-4, AC-5, AC-21 の「設定」の部分）

## U-2：書き忘れを防ぐお知らせ（`src/features/reminder/`）

- 含む Story：S-3〜S-7
- 依存：
  - U-1（iPhone では、ホーム画面に追加していないとお知らせを受け取れない。「設定」の画面の形）
  - `src/lib/db/`（端末への宛先と時刻の表を足す）
  - `src/features/cloud/`（その日に書いたかどうかを、ログインしている人のデータで確かめる）
  - `src/features/account/`（ログアウト・退会のときに宛先を消す）
  - `src/features/privacy/`（説明ページに「お知らせ」の節を足す）

お知らせを受け取る準備（許可・宛先の保存）、送る時刻か確かめて送るしくみ、止めるしくみ。

### Bolt 計画

- Bolt-3：宛先と時刻を保存する表と、保存・変更・削除のサーバーの処理。ログアウト・退会のときに消す（AC-8, AC-10 のサーバーの部分, AC-15, AC-16）
- Bolt-4：「設定」の「お知らせ」の項目（オン・オフ・時刻・使えない理由）と、お知らせを受け取って表示し、押すとホームを開くしくみ（Service Worker）（AC-6, AC-7, AC-9, AC-10, AC-14, AC-20）
- Bolt-5：定期的に「送る時刻か」を確かめ、まだ書いていない人の端末に送る。1 日 1 回まで。使えなくなった宛先を消す（AC-11〜AC-13, AC-17）
- Bolt-6：説明ページの「お知らせ」の節。ログインしていない人のブラウザから外へ送らないことと、幅 375px の E2E（AC-18, AC-19, AC-21）

### テストの方針

- 送る時刻か・書いたかどうか・1 日 1 回までの判断は、画面や通信に依存しない関数にして、単体テストで細かく確かめる
- お知らせを実際に届ける部分は、テストでは「送ったつもりになる」偽物に差しかえる。テスト用のブラウザ（Chromium）では、Apple や Google のお知らせのしくみに本当には届けられないため
- 本物の iPhone と Android で届くことは、取り込んでデプロイしたあとに、開発者が自分の端末で確かめる

#### Bolt-1：マニフェスト・PNG のアイコン・画面の上下の余白

**アプリの名前・開き方（マニフェスト）**

- Next.js の決まった置き場所 `src/app/manifest.ts` に書く。Next.js が `/manifest.webmanifest` として配り、どのページにも `<link rel="manifest">` を入れる

| 項目                 | 値                                                                  |
| -------------------- | ------------------------------------------------------------------- |
| 名前・短い名前       | logling                                                             |
| 説明                 | 日記を書くとキャラクターが育つ、続けたくなる日記アプリ（今と同じ）  |
| 始まりのページ・範囲 | `/`                                                                 |
| 開き方               | `standalone`（アドレス欄のない画面）                                |
| 背景の色・テーマの色 | `#fff8ec`（クリーム色。起動したときの画面と、Android の上の帯の色） |
| 言語                 | `ja`                                                                |
| アイコン             | 192px・512px（ふつう）、512px（切り抜かれる用：`maskable`）         |

- iPhone 向けに、ページの設定に「ホーム画面から開けるアプリ」であることと、名前「logling」を足す（`appleWebApp`）。画面の上の時計や電池の表示は、ふつうの色（`default`）にする
- ページの設定の「テーマの色」も `#fff8ec` にする

**PNG のアイコン**

- もとの絵は、今のファビコン `src/app/icon.svg`（段階 1 の絵）。ここから PNG を作る小さなスクリプト `scripts/make-icons.mjs` を置き、`npm run icons` で作り直せるようにする。作った PNG はリポジトリに入れる（毎回のビルドでは作らない）
- PNG を作る道具は `sharp`。Next.js がすでに「入っていれば使う」部品として入れている 0.35.5 を、開発用の部品として明記する（版は同じ）

| ファイル                             | 大きさ | 使い道                                                        | 絵の大きさ（まわりはクリーム色）          |
| ------------------------------------ | ------ | ------------------------------------------------------------- | ----------------------------------------- |
| `public/icons/icon-192.png`          | 192px  | ホーム画面（Android など）                                    | 80%                                       |
| `public/icons/icon-512.png`          | 512px  | ホーム画面・起動したときの画面                                | 80%                                       |
| `public/icons/icon-maskable-512.png` | 512px  | 丸や角丸に切り抜かれるとき                                    | 60%（切り抜かれても欠けない真ん中の範囲） |
| `src/app/apple-icon.png`             | 180px  | iPhone のホーム画面（Next.js が自動で `apple-touch-icon` に） | 75%                                       |
| `src/app/icon1.png`                  | 32px   | Safari などのファビコン（SVG のファビコンと並べる）           | 絵だけ（背景なし）                        |

**画面の上下の余白**

- 上の帯（`AppHeader`）の上の余白に、画面の上の切り欠きの分（`env(safe-area-inset-top)`）を足す。ブラウザで開いているときは 0 なので、見た目は今と同じ

#### Bolt-3：宛先と時刻の表と、保存・削除のサーバーの処理

送り方と定期的に確かめるしくみは [ADR-0007](../../adr/0007-push-notifications.md) で決めた。Bolt-3 では、宛先を預かるところまでを作る。

**表 `push_subscriptions`**（端末ごとに 1 行。オフにすると行を消す）

| 列                         | 型               | 中身                                                                            |
| -------------------------- | ---------------- | ------------------------------------------------------------------------------- |
| `endpoint`                 | text（主キー）   | お知らせのしくみのアドレス（端末とブラウザごとに 1 つ）                         |
| `user_id`                  | text             | 持ち主。`user` を消すと一緒に消える（退会：AC-16）                              |
| `p256dh`・`auth`           | text             | お知らせを暗号にするための、端末の鍵                                            |
| `remind_minute`            | integer          | 時刻を 0 時からの分で（0〜1410、30 の倍数。21:00 は 1260）                      |
| `time_zone`                | text             | オンにした端末のタイムゾーン（例：`Asia/Tokyo`）                                |
| `last_sent_on`             | date（なしも可） | 最後に送った「その日」（朝 4 時区切り）。同じ日に 2 回送らない（Bolt-5 で使う） |
| `created_at`・`updated_at` | timestamp        |                                                                                 |

- 1 つのブラウザで別のアカウントにログインし直してオンにしたときは、同じ宛先の持ち主を、いまログインしている人に付けかえる

**サーバーの処理**（`src/features/reminder/actions.ts`。`"use server"`。どれも、持ち主はサーバーのログイン情報から決める）

| 処理                                               | 中身                                                                                                             | 結果                                       |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| `getReminder(endpoint)`                            | この端末の宛先が、この人のものとして保存されていれば、時刻を返す（「設定」の表示に使う）                         | オン（時刻）／オフ                         |
| `saveReminder({ subscription, minute, timeZone })` | 宛先と時刻を保存する（なければ作り、あれば時刻とタイムゾーンを変える）。オンにするときと、時刻を変えるときに使う | 成功／ログインしていない／正しくない／失敗 |
| `removeReminder(endpoint)`                         | この人のものなら、その宛先を消す（オフにするとき、ログアウトの前）                                               | 成功／ログインしていない／失敗             |

- 受け取った値は、保存する前にすべて確かめる（`validate.ts`。画面に依存しない関数）
  - 宛先のアドレス：`https` で、ADR-0007 のお知らせのしくみのものだけ。長さは 2,000 文字まで
  - 鍵：URL で使える Base64 の文字だけで、決まった長さの範囲
  - 時刻：0〜1410 の 30 の倍数
  - タイムゾーン：ブラウザが知っている名前（`Intl` で確かめる）
- 失敗したときに、宛先や鍵を記録（ログ）に出さない

**ログアウト・退会のとき**（AC-16）

- ログアウト：アカウントの画面の「ログアウト」で、ログアウトする前に、この端末の宛先を消す（`removeReminder`）。あわせて、ブラウザの側でもお知らせの登録をやめる（宛先が使えなくなり、万一サーバーに残っても、送ったときに消える：AC-17）。宛先を消すのに失敗しても、ログアウトは進める
- 退会：DB の決まり（`user` を消すと一緒に消える）で、すべての端末の宛先と時刻が消える
