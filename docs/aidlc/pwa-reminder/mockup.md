# UI モック：ホーム画面に追加と、書き忘れを防ぐお知らせ（pwa-reminder）

見た目は [mockup.html](mockup.html) で確認する（ファイルをブラウザで開くだけ。外部への通信はしない）。色・フォント・ボタンの大きさは `diary-exp` の [mockup.md](../diary-exp/mockup.md) と、下のタブは `tab-navigation` の [mockup.md](../tab-navigation/mockup.md) と同じ。

## 方針

| 項目                     | 内容                                                                                                                                                     |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ホーム画面のアイコン     | 段階 1 の絵（ファビコンと同じ）を、クリーム色の正方形の真ん中に置く。丸く切り抜かれても欠けないよう、まわりに余白をとる                                  |
| ホーム画面から開いたとき | アドレス欄がない。上の帯は、時計や電池の表示の下から始まる                                                                                               |
| 「設定」の画面           | 見出し「設定」の下に、「お知らせ」と「ホーム画面に追加」の 2 つのまとまり。それぞれ白いカード                                                            |
| お知らせ                 | 「書き忘れのお知らせ」とオン・オフの切り替え。オンのときだけ「時刻」（30 分ごと、はじめは 21:00）と「この端末にだけ届くよ。15 分ほど遅れることがあるよ」 |
| 使えないとき             | 切り替えを薄くして押せなくし、その下の薄いオレンジの枠に理由と使い方を出す                                                                               |
| ホーム画面に追加         | iPhone（Safari）と Android（Chrome）の手順を、番号付きで出す。ホーム画面から開いているときは「✓ ホーム画面から開いているよ」だけ                         |
| 届いたお知らせ           | 題は「logling」、文は「<名前>が待っているよ。今日の日記を書こう」。アイコンはホーム画面と同じ                                                            |

## 画面と文言

| 画面                                    | 対象の AC    | 主な文言                                                                                                                                                                                               |
| --------------------------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1. ホーム画面のアイコン                 | AC-1, AC-2   | 名前「logling」                                                                                                                                                                                        |
| 2. ホーム画面から開いたとき             | AC-1, AC-3   | （ホームの中身は今と同じ）                                                                                                                                                                             |
| 3. 設定（ログインしていない・ブラウザ） | AC-4, AC-9   | 「書き忘れのお知らせ」「まだ日記を書いていない日に、決めた時刻にお知らせするよ」「ログインすると使えるよ。ログインする ›」「ホーム画面に追加すると、アプリのように開けるよ」、iPhone と Android の手順 |
| 4. 設定（ログイン中・iPhone の Safari） | AC-9         | 「iPhone では、ホーム画面に追加して、そこから開くと使えるよ（追加のしかたは下にあるよ）」                                                                                                              |
| 5. 設定（ホーム画面から・オフ）         | AC-5, AC-6   | 「✓ ホーム画面から開いているよ」                                                                                                                                                                       |
| 6. 設定（オン・時刻 21:00）             | AC-6〜AC-8   | 「時刻」「21:00」「この端末にだけ届くよ。15 分ほど遅れることがあるよ」                                                                                                                                 |
| 7. 設定（許可を断ったとき）             | AC-9         | 「お知らせが許可されていないよ。端末の設定で、logling のお知らせを許可してね」                                                                                                                         |
| 8. 届いたお知らせ                       | AC-11, AC-14 | 「logling」「ぴよが待っているよ。今日の日記を書こう」                                                                                                                                                  |

- 対応していないブラウザでは、画面 7 と同じ形で「このブラウザでは、お知らせを使えないよ」
- オン・オフや時刻の保存に失敗したときは、カードの下に「⚠ 保存できなかった…通信できるところで、もう一度ためしてね」を出し、前の状態に戻す（AC-10）
- ホーム画面に追加する方法は「設定」にだけ置き、ホームには出さない

## 判断メモ

- モックへのゲートでの判断：指摘なしで承認（項目名は「書き忘れのお知らせ」、ホーム画面に追加する方法は「設定」にだけ置きホームには出さない、アイコンは段階 1 の絵、iPhone と Android の手順は両方出す）
