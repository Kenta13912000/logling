# Intent：ホーム画面に追加と、書き忘れを防ぐお知らせ（pwa-reminder）

日記が続かない人が、logling をスマホのホーム画面からアプリのように開け、まだ書いていない日には自分で選んだ時刻にお知らせが届くことで、毎日書くきっかけを持てるようにする。

## 対象ユーザー

- 毎日日記を書きたいが、書くのを続けられない人（`diary-exp` と同じ）。主にスマホで使う
- 書くつもりがあっても、夜になると忘れてしまう人
- お知らせを使うのは、ログインしている人のうち、自分でお知らせをオンにした人だけ。ホーム画面に追加だけを使いたい人もいる

## SC（成功条件）

**ホーム画面に追加**

- SC-1：スマホ（iPhone の Safari、Android の Chrome）で logling をホーム画面に追加でき、そのアイコンから開くと、ブラウザの枠のないアプリのような画面で開く。アイコンは logling のキャラクターの絵
- SC-2：ホーム画面に追加する方法が、アプリの中でわかる（iPhone は共有メニューから、など）

**お知らせ**

- SC-3：ログインしている人は、「設定」でお知らせをオンにし、時刻を 30 分ごと（例：21:00、21:30）に選べる。はじめはオフで、オンにしたときにだけブラウザの許可を求める
- SC-4：お知らせがオンの人には、その日の日記をまだ書いていない日だけ、選んだ時刻から、ふつうは 15 分ほど、遅くても 1 時間のうちにお知らせが届く（⑧ で変更）。書いた日は届かない。「その日」は、これまでと同じく朝 4 時で区切る
- SC-5：お知らせを押すと、logling のホーム（今日の日記を書く画面）が開く
- SC-6：「設定」でお知らせをオフにすると、それからは届かない。ログアウト・退会したときも届かなくなる
- SC-7：お知らせを使えないとき（ログインしていない、iPhone でホーム画面に追加していない、許可を断った、対応していないブラウザ）は、その理由と、どうすれば使えるかが「設定」でわかる

**約束と、これまでの動き**

- SC-8：ログインしていない人のブラウザからは、これまでどおり、ほかの場所に何も送らない
- SC-9：説明ページ「日記の保存のしかた」に、お知らせのために預かるもの（端末への宛先と時刻）と、それを消す方法が、ふだんの言葉で書いてある
- SC-10：これまでの機能の動きは変わらない。幅 375px で横スクロールが出ない

## 前提

- 1 つの機能のまま、中を 2 つのかたまりに分ける：先に「ホーム画面に追加」、次に「お知らせ」。取り込みの依頼（PR）も 2 つに分け、ホーム画面に追加だけを先に公開できるようにする
- iPhone でお知らせを受け取れるのは、ホーム画面に追加して、そのアイコンから開いたときだけ（iOS 16.4 以降。Apple の決まり）。Android の Chrome と PC のブラウザは、ホーム画面に追加しなくても受け取れる
- お知らせを送るには、サーバーが「いま送る時刻か」を定期的に確かめる必要がある。Vercel の無料プラン（Hobby）で 30 分ごとに確かめるしくみは、⑤ の設計で比べて ADR に残す（新しい Schedules は 15 分ごとまで動かせるが試験提供の段階で、毎回 0〜15 分ずれる。昔からの Cron Jobs は 1 日 1 回まで）
- お知らせのために、端末への宛先と時刻を、ログインしている人のアカウントに結びつけて DB に保存する。DB の表が増えるので、取り込む前に本番の準備が要る
- 時刻は、オンにした端末の時刻（タイムゾーン）で数える
- 「設定」の画面の「設定は、これから増えるよ」は、お知らせの項目に置きかえる
- `character-evolution` から回した、PNG のアイコン（Safari のファビコン用を含む）もここで作る

## スコープ外

| 内容                                       | 扱い                                   |
| ------------------------------------------ | -------------------------------------- |
| ログインしていない人へのお知らせ           | 扱わない（説明ページの約束を守るため） |
| 1 日に何回もお知らせする・曜日ごとに変える | 扱わない                               |
| お知らせの文を利用者が変える               | 扱わない                               |
| メールでのお知らせ                         | 扱わない                               |
| 通信できないときに書く                     | `offline-write`（12 番）で扱う         |
| キャラの名前・1 日の区切りの時刻・画面の色 | `settings`（9 番）で扱う               |

## 判断メモ

- 作成前に確認した点：「ホーム画面に追加」と「お知らせ」は 1 つの機能のまま、中を 2 つのかたまり・2 つの PR に分ける／お知らせはログインしている人だけ（書いた日は送らないことができ、説明ページの約束も守れる）／書いた日は送らない／時刻は 30 分ごと／お知らせは自分でオンにした人だけで、いつでもオフにできる（開発者の質問「通知がいらない人は受け取らない選択もできるの？」への答え）
- Intent へのゲートでの判断：指摘なしで承認（「15 分ほどのうちに届く」の書き方、時刻はオンにした端末のタイムゾーンで数える、ホーム画面に追加する方法の案内は「設定」に置き、ホームにも出すかは ④ で決める）
