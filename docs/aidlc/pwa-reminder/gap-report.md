# 差分レポート：ホーム画面に追加と、書き忘れを防ぐお知らせ（pwa-reminder）

実装から書き起こした [要件定義書](../../requirements/pwa-reminder.md) と、当初の [intent.md](intent.md)・[stories.md](stories.md)・[mockup.md](mockup.md) を比べた結果。

## 未実装の AC

なし。AC-1〜AC-21 はすべて実装され、テストで確かめている。ただし、お知らせを本物の端末に届けて、押すとホームが開くこと（AC-11〜AC-14）は、テスト用のブラウザではできない。取り込んだあとに開発者の端末で確かめる（下の M）。AC-3 は、PR-1 の取り込み後に開発者の iPhone で確かめた。

## 判断メモ

- C・D は、日記を預かるアプリとして大事な安全の約束で、テストもあるため、新しい AC（AC-22・AC-23）にした。テストの名前にも新しい番号を付けた
- A・B・E・F・G は、設計や作っている途中のゲートで決めたことのため、それぞれの AC の文に書き足した。E は intent.md の SC-4 も合わせた
- H・I・K は、要件定義書への記録だけにした
- J は、この機能の完了に合わせて、`tab-navigation`・`character-evolution`・`account-sync`・`release` の要件定義書、README、ロードマップを更新した
- L・M は、取り込みとデプロイの前後でないとできないため次回へ回し、PR-2 の取り込みの前後の作業として行う
- 差分レポートへのゲートでの判断：提案どおりの対応で承認
