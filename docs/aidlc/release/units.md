# Units：公開（release）

## 全体像

この機能はアプリの画面を作らないため、Unit は `src/features/` のフォルダではなく、作業のまとまりで分ける。

```
U-1 配信の設定（リポジトリの中の設定とテスト）
 └─ U-2 Vercel との連携（Vercel の画面での操作と ADR）
     └─ U-3 公開の仕上げ（README・リポジトリの公開）
```

## U-1：配信の設定（`next.config.ts`・`playwright.config.ts`・`e2e/`）

- 含む Story：S-4（S-1 の確かめ方も用意する）
- 依存：なし
- 受け持つこと：基本的なセキュリティの設定（レスポンスヘッダー）、外部への通信がないことを確かめる E2E テスト、E2E テストを公開版の URL に向けても実行できるようにする設定

### Bolt 計画

- Bolt-1：セキュリティの設定と、外部への通信・計測のスクリプトがないことを確かめる E2E テスト。手元でも公開版でも同じテストを実行できるようにする（AC-8, AC-9, AC-10）

### 設計（⑤で追記）

## U-2：Vercel との連携（Vercel の画面・`docs/adr/0003-*.md`）

- 含む Story：S-1, S-2, S-3, S-6
- 依存：U-1（公開する前に、セキュリティの設定とテストをそろえておく）
- 受け持つこと：公開先の比較と ADR-0003、Vercel のアカウントの作成とプロジェクトの作成（開発者が画面で操作する）、最初の公開、公開版での確認

### Bolt 計画

- Bolt-2：ADR-0003 を書き、Vercel と GitHub を連携して公開する。公開版で E2E テストと手動の確認を行う（AC-1, AC-2, AC-3, AC-4, AC-5, AC-6, AC-7, AC-13。AC-8〜AC-10 は公開版でも確かめる）

### 設計（⑤で追記）

## U-3：公開の仕上げ（`README.md`・GitHub の設定）

- 含む Story：S-5
- 依存：U-2（公開の URL が決まってから）
- 受け持つこと：README への URL の掲載、履歴に秘密情報がないかの確認、リポジトリの公開（開発者が画面で操作する）

### Bolt 計画

- Bolt-3：README に URL を載せ、履歴に秘密情報がないことを確かめてから、リポジトリを公開する（AC-11, AC-12）

### 設計（⑤で追記）

## 実装の順番

| 順番 | Bolt   | Unit | 内容                                     | 理由                                                        |
| ---- | ------ | ---- | ---------------------------------------- | ----------------------------------------------------------- |
| 1    | Bolt-1 | U-1  | セキュリティの設定と E2E テスト          | 公開する前に、安全な状態と確かめ方をそろえる                |
| 2    | Bolt-2 | U-2  | ADR-0003・Vercel との連携・最初の公開    | 設定がそろってから公開する                                  |
| 3    | Bolt-3 | U-3  | README・秘密情報の確認・リポジトリの公開 | 公開の URL が決まり、公開版の動きを確かめてから一般に見せる |

## 確かめ方

| AC                | 確かめ方                                                                                |
| ----------------- | --------------------------------------------------------------------------------------- |
| AC-1, AC-2        | E2E テスト（`diary-exp` のもの）を公開版の URL に向けて実行する。スマホでも手で確かめる |
| AC-3              | 公開版を `http://` で開いて確かめる                                                     |
| AC-4              | この PR をマージしたあと、公開版が更新されることを確かめる                              |
| AC-5              | Vercel の公式の情報で確かめる（わざとビルドを壊す確認はしない）                         |
| AC-6, AC-7        | この PR のページで確かめる。確認用の URL を、ログインしていないブラウザで開いて確かめる |
| AC-8, AC-9, AC-10 | E2E テスト（手元と公開版の両方）                                                        |
| AC-11             | README を確かめる                                                                       |
| AC-12             | 履歴を検索して確かめる。公開はリポジトリの設定画面で行う                                |
| AC-13             | ADR-0003 を確かめる                                                                     |

## PR の単位

Bolt は 3 つで小さめ。ルールどおり、この機能は 1 ブランチ・1 PR（`feat/release`）で進める。

## 判断メモ

- Units へのゲートでの判断：指摘なしで承認。新しい画面がないため ④ UI モックは作らない
