# Intent：公開（release）

採用担当者や日記を続けたい人が、インストールやログインをせずに、URL を開くだけで logling を試せるようにする。

## 対象ユーザー

- ポートフォリオとして logling を見る採用担当者・面接官（短い時間で、実際に動くものを触りたい）
- 日記を続けたい人（スマホのブラウザで開いてすぐ使いたい）
- 開発者自身（変更が公開版にどう反映されるかを、取り込む前に確かめたい）

## SC（成功条件）

- SC-1：公開の URL（`〜.vercel.app`）を開くと、スマホでも PC でも logling が表示され、名前を付けて日記を保存するまでの操作ができる
- SC-2：`main` にマージすると、公開版が自動で新しい内容に更新される
- SC-3：PR を作ると、マージする前に変更を確かめられる、PR ごとの確認用の URL が作られる
- SC-4：公開しても、日記とキャラクターのデータは利用者のブラウザの中だけにあり、外部（Vercel を含む）に送られない
- SC-5：README に公開の URL が載り、GitHub のリポジトリが公開されている
- SC-6：公開先を選んだ理由が ADR に残っている

## 前提

- 公開先は Vercel を第一候補とし、⑤ 設計で他の候補と比べて ADR-0003 に残す
- URL は Vercel の無料のもの（`〜.vercel.app`）を使う
- Vercel のアカウントはこれから作る（GitHub のアカウントで登録する）
- GitHub のリポジトリは、公開がうまくいき README に URL を載せたあと、この機能の最後に公開する（公開の操作は開発者が行う）
- 無料のプランの条件は変わることがあるため、決める時点で公式の情報を確かめる

## スコープ外

| 内容                                            | 扱い                                   |
| ----------------------------------------------- | -------------------------------------- |
| 独自ドメイン                                    | 必要になったら検討                     |
| アクセス解析・速度計測（Vercel Analytics など） | 入れない（日記の外部送信をしない方針） |
| ログイン・クラウド保存                          | `account-sync`                         |
| 公開版に対する E2E テストの自動実行             | 必要になったら検討                     |
| 有料のプラン                                    | 使わない                               |

## 判断メモ

- 作成前に確認した点：リポジトリはまだ非公開で、release の最後に公開する／Vercel のアカウントはこれから作る／URL は Vercel の無料のもの
- Intent へのゲートでの判断：指摘なしで承認
