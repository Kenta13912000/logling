# UI モック：キャラの名前を変える・暗い色の画面（settings）

見た目は [mockup.html](mockup.html) で確認する（ファイルをブラウザで開くだけ。外部への通信はしない）。明るい色の見た目・ボタンの大きさ・下のタブは、`pwa-reminder` の [mockup.md](../pwa-reminder/mockup.md) と同じ。

## 方針

| 項目                 | 内容                                                                                                                                                  |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 「キャラクター」     | 「設定」のいちばん上。白いカードに「名前」と今の名前、右に「名前を変える」                                                                            |
| 名前を変える流れ     | 別の画面や窓は出さず、カードの中身が入力 → 確認と変わる。入力欄には今の名前が入っている                                                               |
| 確認                 | 「『<新しい名前>』に変える？」と「経験値やレベル、日記はそのままだよ」。「変える」「やめる」                                                          |
| 変えたあと           | カードがふだんの形に戻り、新しい名前が出る（お祝いの表示などは出さない）                                                                              |
| 暗い色の色合い       | 背景は暗い茶色、カード・帯・タブは少し明るい茶色、文字は明るいクリーム色。今のクリーム・茶色・オレンジの雰囲気を保つ                                  |
| ボタン               | 明るい色と同じオレンジ（#c2410c）に白い文字                                                                                                           |
| リンク・今いるタブ   | 暗い背景で読めるよう、明るめのオレンジ（#fb8c4a）にする                                                                                               |
| 注意の文字           | 明るめの赤（#f87171）にする                                                                                                                           |
| 確認の窓・お知らせ   | 窓は少し明るい茶色、後ろの幕は黒（60%）。経験値のお知らせ（トースト）は、明るい色と同じく「文字の色の地に背景の色の文字」で、暗い色では明るい地になる |
| キャラクターの絵     | 暗い色のときは、絵の後ろに薄いクリーム色（#fff8ec）の丸を敷く（案 B）。ひげや足もとの影も明るい色のときと同じに見える。絵のファイルは変えない         |
| 下のタブのアイコン   | 今と同じ線の絵。線は文字と同じ色をたどるので、暗い色ではほかのタブは薄い文字の色（#c4b09a）、今いるタブは明るめのオレンジで、中を薄いオレンジで塗る   |
| ブラウザの上の帯の色 | 暗い色のときは背景と同じ #1f1813                                                                                                                      |

## 画面と文言

| 画面                                        | 対象の AC         | 主な文言                                                                                                                                                                              |
| ------------------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. 設定（ふだん）                           | AC-1              | 「キャラクター」「名前」「名前を変える」                                                                                                                                              |
| 2. 新しい名前を入れる                       | AC-2, AC-3        | 「新しい名前（10 文字まで）」「この名前にする」「やめる」。「⚠ 名前を入れてね」「⚠ 名前は 10 文字までにしてね」                                                                       |
| 3. 確認                                     | AC-2, AC-9        | 「『ちびすけ』に変える？」「経験値やレベル、日記はそのままだよ」「変える」「やめる」。保存中は「保存しているよ…」                                                                     |
| 4. 変えたあと・失敗したとき・名前を付ける前 | AC-4, AC-9, AC-10 | 「⚠ 保存できなかった…通信できるところで、もう一度ためしてね」「⚠ ほかの端末で、キャラクターがなくなっていたよ。最新の内容を表示したよ」「まだ名前がないよ。ホームで名前を付けてね ›」 |
| 5. ホーム（暗い色）                         | AC-11〜AC-13      | （中身は今と同じ）                                                                                                                                                                    |
| 6. 設定（暗い色）                           | AC-12             | （中身は画面 1 と同じ）                                                                                                                                                               |
| 7. 確認の窓（暗い色）                       | AC-13             | （中身は今の日記を消す確認と同じ）                                                                                                                                                    |

- 名前を付ける画面の確認の文は「名前はあとから『設定』で変えられるよ」にする（AC-5。見た目は今と同じ）
- 今と同じ名前で「この名前にする」を押したときは、確認を出さずに閉じる（AC-3）

## 暗い色の明るさの差（WCAG のコントラスト比）

ふつうの文字は 4.5 : 1 以上、入力欄の枠やバーなど文字でないものは 3 : 1 以上が目安。

| 組み合わせ                          | 比                 |
| ----------------------------------- | ------------------ |
| 文字 / 背景・カード                 | 14.47 / 13.02      |
| 薄い文字 / 背景・カード             | 8.36 / 7.53        |
| リンク / 背景・カード・薄いオレンジ | 7.47 / 6.72 / 5.37 |
| 注意の文字 / 背景・カード           | 6.34 / 5.70        |
| ボタンの白い文字 / オレンジ         | 5.18               |
| 消すボタンの白い文字 / 赤           | 6.57               |
| 入力欄の枠 / カード（文字でない）   | 6.72               |
| 経験値のバー / 下地（文字でない）   | 4.14               |

- カードと背景の境目の線（#3d3027）は飾りとして扱う。カードは背景より明るい色なので、線がなくても区別できる

## 判断メモ

- 暗い色のキャラクターの絵は、後ろに薄いクリーム色の丸を敷く案 B にした（ひげや影まで見えるため。開発者の判断）。名前を変えたあとは、カードを元の形に戻すだけにする
- 見本の下のタブが仮の四角だったため、実物と同じアイコンにした（開発者の指摘。実装ではアイコンの線が文字の色をたどるので、暗い色でも出る）
- 明るい色の、薄いオレンジの枠の中のリンク（明るさの差 4.33）は、明るい色は今と同じ見た目という約束（AC-11）のため、今回は直さない
- モックへのゲートでの判断：上の点を反映して承認
