実装から書き起こした [要件定義書](../../requirements/settings.md) と、当初の [intent.md](intent.md)・[stories.md](stories.md)・[mockup.md](mockup.md) を比べた結果。

## 未実装の AC

なし。AC-1〜AC-15 はすべて実装され、テストで確かめている。ただし、本物の iPhone での見え方（名前の変更、暗い色、ホーム画面から開いたときの上の帯の色：AC-14）は、取り込んでデプロイしたあとに開発者の端末で確かめる（下の J）。

## 判断メモ

- A・B・D・E・F・G は、設計や作っている途中のゲートで決めたことのため、それぞれの AC の文（stories.md の「⑧ で追記」）に書き足した。E は mockup.md にも書き足した
- C は、要件定義書への記録だけにした
- H は、ロードマップの「機能以外の作業」に足した（明るい色の見た目を今と同じに保つ約束のため、この機能では直さない）
- I は、この機能の完了に合わせて、`diary-exp`・`tab-navigation`・`character-evolution`・`pwa-reminder` の要件定義書、README、ロードマップ、開発の記録を更新した
- J は、取り込みとデプロイのあとでないとできないため次回へ回し、取り込みのあとの作業として行う
- 差分レポートへのゲートでの判断：提案どおりの対応で承認（H の中身を確かめてから承認）
- J の実行結果：公開中のサイトでの E2E テスト 38 件と、開発者の iPhone での確かめ（名前を変える・暗い色・上の帯の色）が、すべて終わった。記録は別のドキュメントの PR で残した
