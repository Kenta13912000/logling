# Intent：キャラの名前を変える・暗い色の画面（settings）

日記を続けている人が、あとからキャラクターの名前を自分で変えられ、夜や暗い場所でも端末の設定に合わせた暗い色の画面で、まぶしくなく日記を書けるようにする。

## 対象ユーザー

- 毎日日記を書きたいが、書くのを続けられない人（`diary-exp` と同じ）。主にスマホで、寝る前などに書く
- 名前を付けたあとで、別の名前にしたくなった人
- スマホを暗い色の設定（ダークモード）で使っている人

## SC（成功条件）

**キャラの名前を変える**

- SC-1：「設定」に「キャラクター」のまとまりがあり、今の名前と、名前を変える入口がある。名前を付ける前は、ホームで名前を付けるよう案内する
- SC-2：新しい名前を入れて確かめると、名前が変わる。決まりは名前を付けるときと同じ（前後の空白を除いて 1〜10 文字、決める前に確認がある）。何度でも変えられる
- SC-3：名前を変えても、経験値・レベル・すがた・日記・連続記録は変わらない。変えた名前は、ホーム・振り返り・レベルアップのお知らせ・書き忘れのお知らせなど、名前が出るところすべてに出る
- SC-4：ログイン中は、変えた名前がほかの端末でも同じになる。保存に失敗したときは、前の名前のままで、そのことがわかる

**暗い色の画面**

- SC-5：端末が暗い色の設定のとき、logling の画面も暗い色になる。明るい設定のときは、今と同じ見た目。「設定」に色を選ぶ項目はなく、端末の設定を変えると、そのまま切り替わる
- SC-6：暗い色でも、文字・ボタン・入力欄・キャラクターの絵・下のタブ・お知らせ・確認の窓が、はっきり読める

**これまでの動き**

- SC-7：これまでの機能の動きは変わらない。幅 375px で横スクロールが出ない

## 前提

- キャラクターの名前は、今もブラウザの中（ログインしていないとき）と、インターネット上の保管場所（ログイン中）の両方に入っている。保存する場所は増えない（DB の表は変えない。名前を書きかえる処理を足す）
- 名前の決まりは、`diary-exp` の名前を付けるときのもの（`validateName`）をそのまま使う
- 暗い色は、ブラウザが教えてくれる端末の設定（`prefers-color-scheme: dark`）で切り替える。端末の中にも保管場所にも、何も覚えない
- 暗い色の色合いは、④ の画面の見本で決める。今のクリーム色・茶色・オレンジ色の雰囲気を、暗い色でも保つ

## スコープ外

| 内容                                       | 扱い                                                              |
| ------------------------------------------ | ----------------------------------------------------------------- |
| 1 日の区切りの時刻を変える                 | 作らない（朝 4 時のまま）。これまでの機能の計算に広くかかわるため |
| 画面の色を自分で選ぶ（明るい・暗いの切替） | 作らない（端末の設定に合わせるだけ）                              |
| 名前を変えられる回数の制限・名前の履歴     | 扱わない                                                          |
| キャラクターを作り直す・複数のキャラクター | 扱わない                                                          |

## 判断メモ

- 作成前に確認した点：1 日の区切りの時刻はやめる（開発者の判断）／画面の色は端末の設定に合わせるだけで、選ぶ項目は作らない／名前は今の決まりで何度でも変えられる
- Intent へのゲートでの判断：指摘なしで承認（名前を変える入口は「設定」の中、DB の表は変えない、暗い色の色合いは ④ で決める、PR は 1 つのつもり）
