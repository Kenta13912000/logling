# UI モック：ログインとクラウド保存（account-sync）

見た目は [mockup.html](mockup.html) で確認する（ファイルをブラウザで開くだけ。外部への通信はしない）。色・フォント・ボタンの大きさは `diary-exp` の [mockup.md](../diary-exp/mockup.md) と同じ。キャラクターの絵は `character-evolution` と同じ切り取り方で出す。

## 方針

| 項目             | 内容                                                                                                                                                                                      |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ログインの入口   | 上の帯の右に「アカウント ›」を足す（「ふりかえる ›」の右）。名前を付ける前の画面にも「ほかの端末で使っていた人は ログイン ›」を出す（新しい端末で、名前を付ける前にログインできるように） |
| アカウントの画面 | 新しいページ（`/account`）。ログインしていないときは、ログインで何ができるかと Google のボタン。ログイン中は、メールアドレス・ログアウト・退会。どちらからも説明ページへ行ける            |
| Google のボタン  | Google の決まり（ブランドの指針）どおりの見た目にする。モックの見た目は仮                                                                                                                 |
| 退会の入口       | アカウントの画面のいちばん下に、注意の色の文字のリンクで置く（ログアウトと間違えて押さないように離す）                                                                                    |
| 消える操作の確認 | 引き継ぎで選ばなかった方を消す確認と、退会の確認は、これまでの「消す前の確認」と同じ形。消えるもの（名前・レベル・日記の件数）と「元にはもどせないよ。」を出す                            |
| 引き継いだあと   | ホームに戻り、下にお知らせ「☁ <名前> と日記 N 件をアカウントに移したよ」を出す（経験値のお知らせと同じ出し方）                                                                            |
| 失敗したとき     | これまでの「⚠ 保存できなかった…」と同じく、ページの上に注意の色で出す                                                                                                                     |
| ログイン中の表示 | アカウントの画面で、メールアドレスと「☁ 日記はクラウドに保存されているよ」を出す。ホームの見た目は、ログインしていないときと同じにする                                                    |

## 画面と文言

| 画面                                  | 対象の AC          | 主な文言                                                                                                                        |
| ------------------------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| 1. ホーム（ログインしていない）       | AC-1, AC-2         | 上の帯に「アカウント ›」                                                                                                        |
| 2. 名前を付ける前（新しい端末）       | AC-2               | 「ほかの端末で使っていた人は ログイン ›」                                                                                       |
| 3. アカウント（ログインしていない）   | AC-2, AC-3, AC-7   | 「ログインすると、スマホでも PC でも、同じキャラクターと日記で続きが書けるよ」「Google でログイン」「日記の保存のしかた ›」     |
| 4. ログインできなかった               | AC-5               | 「⚠ ログインできなかった…もう一度ためしてね。このブラウザの日記はそのまま残っているよ」                                         |
| 5. 読み込み中／読み込めなかった       | AC-12              | 「読み込んでいるよ…」／「データを読み込めなかった…」「通信できるところで、もう一度ためしてね」「もう一度読み込む」              |
| 6. 保存できなかった（ログイン中）     | AC-11              | 「⚠ 保存できなかった…通信できるところで、もう一度「日記をのこす」を押してね」。書いていた文は入力欄に残る                       |
| 7. ほかの端末でもう書かれていた       | AC-13              | 「⚠ ほかの端末で、今日の日記がもう書かれていたよ。最新の内容を表示したよ」「この端末で書いていた文（保存されていないよ）」      |
| 8. 初めてのログイン（アカウントが空） | AC-14, AC-15       | 「☁ ぴよ と日記 12 件をアカウントに移したよ」                                                                                   |
| 9. 両方にキャラクターがあるとき       | AC-18              | 「どちらのキャラクターで続ける？」「このブラウザ」「アカウント（ほかの端末）」「ぴよ で続ける」                                 |
| 10. 選んだあとの確認                  | AC-19, AC-20       | 「ぴよ で続ける？」「アカウントの たま（Lv. 3・日記 5 件）は消えるよ。」「元にはもどせないよ。」「たま を消して ぴよ で続ける」 |
| 11. アカウント（ログイン中）          | AC-4, AC-22, AC-31 | メールアドレス、「ログアウト」「ログアウトすると、この端末には日記もキャラクターも残らないよ」「退会する」                      |
| 12. 退会の確認                        | AC-25, AC-28       | 「退会する？」「ぴよ（Lv. 6）と日記 12 件が、すべて消えるよ。」「Google アカウントそのものは消えないよ」                        |
| 13. 日記の保存のしかた（説明ページ）  | AC-30, AC-31       | ログインしないとき／したとき／誰が読めるか／ログアウトと退会／Google の許可を取り消すには                                       |

- ログアウトしたあとは、画面 2（名前を付ける前）になる（AC-22）
- 退会したあとも、画面 2 になる（AC-26）
- 移せなかったとき（AC-15）・退会できなかったとき（AC-28）は、画面 4 と同じ形で、ページの上に失敗したことを出す
- 説明ページの中身の細かいところ（DB の場所、Google から受け取る情報など）は、DB・認証の ADR に合わせて Bolt-7 で仕上げる

## 判断メモ

- ゲートで出た案：上の帯のリンク（ふりかえる・アカウント）を、画面の下のタブ（ホーム・ふりかえる・アカウント）で切り替える形にしたい。範囲が広がる（`diary-history` の画面とテストも直す）ため、この機能では上の帯のまま作り、タブはこの機能の次の機能 `tab-navigation` として作る（ロードマップに追加）
- モックへのゲートでの判断：上記を反映して承認（説明ページの「不具合の調査など、必要なとき以外は見ません」、画面 7 で書いていた文を別の枠に残す形、退会のリンクをいちばん下に離して置く形も、このまま）
