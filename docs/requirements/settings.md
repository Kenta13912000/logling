# 要件定義：キャラの名前を変える・暗い色の画面（settings）

実装（`feat/settings` の `0e49584` 時点）のコードとテストから書き起こした、この機能が実際に満たしている要件。計画との比較は [gap-report.md](../aidlc/settings/gap-report.md) にある。

## 概要

「設定」のいちばん上に「キャラクター」のまとまりを置き、名前を付けるときと同じ決まりで、何度でも名前を変えられるようにした。経験値・レベル・日記はそのまま。あわせて、端末が暗い色の設定（ダークモード）のときは、logling の画面も暗い色になるようにした。色を選ぶ項目はなく、何も覚えない。DB の表は変えていない。

## キャラクターの名前を変える

### 「設定」の「キャラクター」

- 「設定」の見出しのすぐ下、「お知らせ」「ホーム画面に追加」より上に、見出し「キャラクター」と白いカード（暗い色では少し明るい茶色）を置く
- カードの中身は、状態によって変わる

| 状態                                 | カードの中身                                                                                  |
| ------------------------------------ | --------------------------------------------------------------------------------------------- |
| ふだん                               | 「名前」と今の名前、右に「名前を変える」ボタン                                                |
| 名前を付ける前                       | 「まだ名前がないよ。ホームで名前を付けてね ›」（ホームへのリンク）                            |
| 読み込み中（ログイン中）             | 「読み込んでいるよ…」                                                                         |
| 保管場所を読めなかった（ログイン中） | 「データを読み込めなかった…」「通信できるところで、もう一度ためしてね」と「もう一度読み込む」 |
| ブラウザの中のデータがこわれている   | 「データを読めなかったよ。ホームで直してね ›」（直す操作はホームにだけある）                  |

### 名前を変える流れ

別の画面や窓は出さず、カードの中身が入れかわる。

| 段階 | 中身                                                                   | ボタン                                                       |
| ---- | ---------------------------------------------------------------------- | ------------------------------------------------------------ |
| 入力 | 「新しい名前（10 文字まで）」と、今の名前が入った入力欄                | 「この名前にする」・「やめる」（何も変えずに閉じる）         |
| 確認 | 「「<新しい名前>」に変える？」と「経験値やレベル、日記はそのままだよ」 | 「変える」（保存）・「やめる」（入れた名前のまま入力に戻る） |

- 名前の決まりは、名前を付けるときと同じ（前後の空白を除いて 1〜10 文字）。空なら「⚠ 名前を入れてね」、11 文字以上なら「⚠ 名前は 10 文字までにしてね」を入力欄の下に出し、先へ進まない。誤りの文は、名前を付ける画面と同じもの（`name.ts` の `NAME_ERROR_MESSAGES`）を使う
- 確認には、前後の空白を除いた名前を出す。今と同じ名前のときは、確認を出さず、保存もせずに閉じる
- 何度でも変えられる。回数の制限や名前の履歴はない
- 入力に入ると入力欄に、確認に入ると確認の文に、ふだんに戻ると「名前を変える」ボタンに、フォーカスを移す（読み上げで変わったことがわかる）。開いた時点では、どこにもフォーカスを移さない
- 入力欄の文字は 16px（iPhone の Safari で、入力欄を押したときに画面が拡大されないように）

### 保存

| 状態               | 保存先                                                                                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| ログインしていない | ブラウザの中。名前だけを変えたデータを書く（経験値・始めた日・日記はそのまま）                                                         |
| ログイン中         | サーバーの処理 `renameCloudCharacter(name)` で保管場所の名前の列だけを書きかえ、返ってきた最新のデータを出す。ブラウザの中には書かない |

- 保存している間は、「変える」が「保存しているよ…」になり、「変える」「やめる」とも押せない
- 失敗したとき（通信できない・サーバーで失敗）は、前の名前のままで、カードの中に「⚠ 保存できなかった…通信できるところで、もう一度ためしてね」
- ログイン中に、ほかの端末でキャラクターがなくなっていた（退会・引き継ぎの選び直しなど）ときは、名前を変えずに最新の内容に切りかえ（名前を付ける前の表示になる）、「⚠ ほかの端末で、キャラクターがなくなっていたよ。最新の内容を表示したよ」
- お知らせは、もう一度「名前を変える」を押すと消える

### サーバーの処理

- `renameCloudCharacter(name)`（`src/features/cloud/actions.ts`。`"use server"`）
  - 持ち主は、ブラウザから送られた値ではなく、サーバーのログイン情報で決まる。ログインしていなければ「ログインしていない」を返し、DB に触れない
  - 名前は、サーバーでも名前を付けるときと同じ決まりで確かめる（`parseName`。文字でないもの・空・11 文字以上は「入力が正しくない」）
  - ログインしている人のキャラクターの名前の列だけを書きかえる（`renameCharacter`）。ほかの人のキャラクターは変わらない。キャラクターがなければ「キャラクターがない」と最新のデータを返す
  - 失敗したときに、名前を記録（ログ）に出さない
- キャラクターを作るときの確かめ（`parseCharacter`）も、同じ `parseName` を使うようにした（決まりは同じ）

### 名前が出るところ

- 変えた名前は、ホームのキャラクターの欄、振り返り（日記を消す確認の「<名前> のレベルが…下がるよ。」）、レベルアップのお知らせ、退会の確認、書き忘れのお知らせの文に出る
- ホームや振り返りは、開くたびにデータを読み直す（ブラウザの中は、書きかえると開いているすべての画面に知らせが行く）。書き忘れのお知らせは、送るときに保管場所の名前を読む

### 名前を付ける画面

- 確認の文「名前はあとから変えられないよ」を「名前はあとから『設定』で変えられるよ」にした。ほかは変えていない

## 暗い色の画面

切りかえ方と色の決まりは [ADR-0008](../adr/0008-dark-mode.md) で決めた。

### 切りかえ方

- ブラウザが教えてくれる端末の設定（`prefers-color-scheme: dark`）だけで切りかえる。CSS の中で色の決まり（CSS の変数）の値を置きかえる。JavaScript は使わず、開いた瞬間から正しい色で出る。開いたまま端末の設定を変えると、そのまま切りかわる
- 色を選ぶ項目はなく、端末の中にも保管場所にも何も覚えない
- `color-scheme: light dark` を付け、選ぶ欄の一覧やスクロールの帯なども端末の設定に合わせる

### 色の決まり

| 名前          | 使い道                           | 明るい色（今と同じ） | 暗い色          |
| ------------- | -------------------------------- | -------------------- | --------------- |
| `cream`       | ページの背景                     | #fff8ec              | #1f1813         |
| `surface`     | カード・帯・タブ・窓・入力欄の地 | #ffffff              | #2a211b         |
| `ink`         | 文字                             | #3f2d1c              | #f3e8d8         |
| `ink-muted`   | 薄い文字・ほかのタブ             | #7a6450              | #c4b09a         |
| `line`        | 線・枠                           | #ecdcc4              | #3d3027         |
| `ember`       | オレンジのボタンの地（白い文字） | #c2410c              | #c2410c（同じ） |
| `link`        | リンク・今いるタブ               | #c2410c              | #fb8c4a         |
| `danger`      | 消す・退会・選び直しのボタンの地 | #b42318              | #b42318（同じ） |
| `alert`       | 注意の文字                       | #b42318              | #f87171         |
| `ember-soft`  | 案内の枠・今いるタブの塗り       | #fde7d6              | #4a2c1a         |
| `honey`       | 経験値のバー                     | #d97706              | #d97706（同じ） |
| `honey-track` | 経験値のバーの下地・連続記録の帯 | #f6e7cf              | #3a2e22         |
| `switch-off`  | 切りかえのオフの地               | #d8cbb8              | #5a4a3d         |
| `line-strong` | 時刻を選ぶ欄の枠                 | #d8c4a6              | #6b5a4a         |
| `ok`          | 「✓ ホーム画面から開いているよ」 | #3f6b2a              | #9ccc84         |
| `scrim`       | 確認の窓の後ろの幕               | 濃い茶色の 45%       | 黒の 60%        |

- 画面の部品は、色を直接書かず、色の決まりの名前で書く。例外は、Google のロゴの色、切りかえのつまみ（どちらでも白）、Google のログインのボタン（下）だけ
- 経験値のお知らせと、移したお知らせ（トースト）は、文字の色の地に `surface` の文字。暗い色では明るい地に暗い文字になる
- Google のログインのボタンは、暗い色では Google の決まりの暗い色（地 #131314・枠 #8e918f・文字 #e3e3e3）

### 明るさの差（WCAG のコントラスト比）

暗い色の値は、次を満たす（`palette.test.ts` が `globals.css` から値を読んで計算する）。

- 文字・薄い文字・リンク・注意の文字が、背景・カード・案内の枠の上で 4.5 : 1 以上（いちばん低いのは、案内の枠の上の注意の文字で 4.56）
- 「✓」の緑が、背景・カードの上で 4.5 : 1 以上。ボタンの白い文字（オレンジ 5.18・赤 6.57）と、お知らせの文字が 4.5 : 1 以上
- 経験値のバーと下地、今いるタブ・ほかのタブ・切りかえのオンとカードが 3 : 1 以上
- 明るい色は今と同じ値のため、今からある「明るい色の案内の枠の中のリンク」（4.33）はそのまま（[gap-report.md](../aidlc/settings/gap-report.md)）

### キャラクターの絵

- 暗い色のときだけ、絵の後ろに薄いクリーム色（#fff8ec）の丸を描く。茶色の線やひげが、暗い背景にとけないように
- 丸は、段階ごとに SVG から測った「描かれている範囲を囲む最小の丸」に少し余白を足したもの（`stages.ts` の `backing`）。丸は背景の模様として描き、絵を丸く切り抜かない
- 余白ごとの絵（名前を付ける画面・振り返り・レベルアップなど）は、その丸をそのまま描く。絵の大きさは変わらない
- 小さい枠に合わせて切り出した絵（ホームの帯・日記の横・引き継ぎ）は、丸が枠より大きいため、暗い色のときだけ、絵を丸の中心に向けて縮め（段階 1〜5 で 94・98・86・82・84%）、丸が枠に収まるようにする
- 明るい色のときは、丸も縮みもない（今と同じ）

### ブラウザの上の帯の色

- `theme-color` を 2 つにした：明るい色の設定のときは #fff8ec、暗い色の設定のときは #1f1813（どちらもページの背景と同じ。`theme-color.ts`）
- ホーム画面に追加したときの起動の画面の色（マニフェスト）は、明るい・暗いを分けられないため、クリーム色のまま

## ページ全体

- 幅 375px で、「設定」の画面（名前を変える流れの間も）に、明るい色でも暗い色でも横スクロールが出ない
- DB の表・通信先・保存の仕方は変えていない。部品（ライブラリ）も増えていない
