# 要件定義：下のタブで画面を切り替える（tab-navigation）

実装（`feat/tab-navigation` の `fb5e682` 時点）のコードとテストから書き起こした、この機能が実際に満たしている要件。計画との比較は [gap-report.md](../aidlc/tab-navigation/gap-report.md) にある。

## 概要

どの画面にも、画面の下に「ホーム」「ふりかえる」「その他」の 3 つのタブを出し、親指の届く場所で画面を移れるようにした。アカウント・日記の保存のしかた・設定は「その他」にまとめた。上の帯は「logling」だけになり、画面を移るリンクは下のタブにまとまった。保存の仕方や DB は変えていない。

## 画面の組み立て

- 上の帯と下のタブは、全ページ共通の枠（`src/app/layout.tsx`）に置く。各ページは真ん中の中身だけを受け持つ
- 枠の幅は最大 480px で真ん中に寄せる（これまでと同じ）。PC でも同じ下のタブを使う

### 上の帯

- 「logling」を真ん中に置くだけ。リンクはない
- 見出しにはしない（各ページの見出しと重ならないように）。ホームには、読み上げ用の見えない見出し「ホーム」を置く。ほかのページは「ふりかえり」「アカウント」「日記の保存のしかた」「その他」「設定」の見出しがある

### 下のタブ

| タブ       | アイコン | 行き先     | 今いるタブになるページ                       |
| ---------- | -------- | ---------- | -------------------------------------------- |
| ホーム     | 家       | `/`        | `/`                                          |
| ふりかえる | 開いた本 | `/history` | `/history`                                   |
| その他     | 点 3 つ  | `/more`    | `/more`・`/account`・`/privacy`・`/settings` |

- 白い帯に 3 つを等しい幅で並べ、上にアイコン、下に名前（11px）。1 つの高さは 56px、上に 1px の線。iPhone の画面の下の線の分の余白を足す
- 今いるタブは、アイコンと名前がオレンジ色になり、アイコンの中を薄いオレンジで塗る。それ以外は茶色がかった灰色
- 今いるタブのリンクには「今のページ」の印（`aria-current="page"`）を付ける。どのタブにも入らないページ（ないページなど）では、どこにも付けない
- タブのまとまりは「メインメニュー」という名前の `<nav>`。アイコンは飾りとして読み上げない（読み上げられる名前は「ホーム」「ふりかえる」「その他」だけ）
- 名前を付ける前も出る。名前を付ける前に「ふりかえる」を開くと、これまでどおり「ホームで名前を付けてね」と出る

### 「その他」（`/more`）

- 見出し「その他」と、白いカードに 3 行。行の左にアイコン、右に「›」（読み上げない）

| 行                 | アイコン | 行き先      | 添える文                                                                             |
| ------------------ | -------- | ----------- | ------------------------------------------------------------------------------------ |
| アカウント         | 人       | `/account`  | ログイン中なら「ログイン中：<メールアドレス>」、そうでなければ「ログインしていない」 |
| 日記の保存のしかた | 盾       | `/privacy`  | なし                                                                                 |
| 設定               | 歯車     | `/settings` | なし                                                                                 |

- ログインしているかを確かめている間は、アカウントの行に何も添えない
- タブのタイトルは「その他 | logling」

### 設定（`/settings`）

- 見出し「設定」と、「設定は、これから増えるよ」「たとえば、日記を書く時間のお知らせなど」だけ。タブのタイトルは「設定 | logling」
- （`pwa-reminder` で変更）「これから増えるよ」をなくし、まとまりごとに小さな見出しと白いカードを並べる形にした。中身は「お知らせ」（書き忘れのお知らせ）と「ホーム画面に追加」。あわせて、ホーム画面から開いたときのために、上の帯の上に画面の上の切り欠きの分の余白を足した。詳しくは [pwa-reminder の要件定義](pwa-reminder.md) を参照
- （`settings` で変更）いちばん上に「キャラクター」（名前を変える）のまとまりを足した。詳しくは [settings の要件定義](settings.md) を参照

### これまでの画面から変わったところ

| 画面               | 変わったところ                                                                                    |
| ------------------ | ------------------------------------------------------------------------------------------------- |
| ホーム             | 上の帯の「ふりかえる ›」「アカウント ›」をなくした。見出し「logling」は見えない見出し「ホーム」に |
| ふりかえり         | 上の帯の「‹ ホーム」をなくした。日記がないときなどの案内の「ホームへ」ボタンは残す                |
| アカウント         | 上の帯の「‹ ホーム」をなくした                                                                    |
| 日記の保存のしかた | 上の帯の「‹ ホーム」をなくした                                                                    |

- 名前を付ける画面の「ほかの端末で使っていた人は ログイン ›」と、ホームのいちばん下のフッター（アプリの説明と「日記の保存のしかた」）は残す

## 文字を打っている間

- 文字を打つ欄（`textarea`、文字・メール・検索などの `input`）が選ばれている間は、タブを隠す。見えなくするだけでなく、読み上げやキーボード操作の対象からも外す（`hidden`）。対象は、日記・名前・振り返りの入力欄
- 入力欄から別の入力欄に移ったときは、隠したまま。ボタンなど入力欄以外に移ったり、入力欄の外を押したりすると、また出る
- チェックボックス・ラジオボタン・ボタンなど、文字を打たないものが選ばれても隠さない
- ボタンを押して入力欄から離れるときは、押し終わってからタブを出す。押している途中にタブが出て、画面のいちばん下のボタンにかぶり、押せなくなるのを防ぐ
- 名前を付ける画面は、開いた時点では入力欄が選ばれていないので、タブが出る（開発中のサーバーで準備の処理が 2 回動いても同じ）

## ほかのものにかぶらない

- 全ページ共通の枠の下に、タブの高さ（56px と上の線 1px）と iPhone の画面の下の線の分の余白をとる。いちばん下まで動かすと、最後の内容（ホームのフッターなど）がタブより上に見える
- ページの設定に `viewport-fit=cover` を足した。iPhone の画面の下の線の分の長さを、ブラウザから受け取れるようにするため

| もの                                   | 出る場所・重なり                                                             |
| -------------------------------------- | ---------------------------------------------------------------------------- |
| 経験値のお知らせ                       | 画面の上（上の帯のすぐ下）。これまでと同じで、タブにはかぶらない             |
| 移したお知らせ（ログイン後の引き継ぎ） | タブから 16px 上（これまでは画面の下から 24px）                              |
| 消す・レベルアップの確認の窓           | ブラウザの確認の窓のしくみ（`<dialog>`）で、いちばん手前。後ろは押せない     |
| 退会・引き継ぎ（どちらで続ける）の確認 | タブより手前に出し、タブも暗くなる（重なりの順番：ページ < タブ < 確認の窓） |

## ページ全体

- 幅 375px で、6 つの画面（ホーム・ふりかえり・その他・アカウント・日記の保存のしかた・設定）のどれでも横スクロールが出ない。タブは高さも幅も 44px 以上
- 色は `diary-exp` の見本と同じ。今いるタブの薄いオレンジ（`#fde7d6`）だけを足した
- （`settings` で変更）色は色の決まりの名前で書くようにした（白い帯は `surface`、今いるタブの色は `link`、薄いオレンジは `ember-soft`）。端末が暗い色の設定のときは、タブの帯は少し明るい茶色、今いるタブは明るめのオレンジになる。詳しくは [settings の要件定義](settings.md) を参照
- 保存の仕方・DB・通信先は変えていない
