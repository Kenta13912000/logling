# 要件定義：キャラクターの成長（character-evolution）

実装（`feat/character-evolution` の `3a95202` 時点）のコードとテストから書き起こし、⑧ の差分確認で決めた対応（AC-17 の追加、AC-6 の文の更新）を反映した、この機能が実際に満たしている要件。計画との比較は [gap-report.md](../aidlc/character-evolution/gap-report.md) にある。

## 概要

キャラクターのすがたが、レベルに応じて 5 段階で変わる。絵は開発者が描いたオリジナルの SVG。段階が変わるレベルに上がるとお知らせで伝え、日記を消してレベルが下がれば、すがたも戻る。ブラウザのタブのアイコン（ファビコン）は、段階 1 の絵をもとにしたものにした。

## 段階

| 段階 | レベル  | 名前         | 絵                              |
| ---- | ------- | ------------ | ------------------------------- |
| 1    | 1〜4    | ねこだま     | `public/characters/stage-1.svg` |
| 2    | 5〜9    | ころねこ     | `public/characters/stage-2.svg` |
| 3    | 10〜14  | ちびねこ     | `public/characters/stage-3.svg` |
| 4    | 15〜19  | えらそうねこ | `public/characters/stage-4.svg` |
| 5    | 20 以上 | ねこ像       | `public/characters/stage-5.svg` |

- 段階は、保存されている経験値の合計から決まるレベルだけで決める。新しく保存するものはない
- 段階の名前・レベルの区切り・絵のファイル・小さい枠で見せるときの切り取る範囲は、`src/features/evolution/stages.ts` の表 1 か所にまとめてある

## 画面と動き

### 絵を出す場所

| 場所                                                             | 絵         | 大きさ                 | 読み上げ                                 |
| ---------------------------------------------------------------- | ---------- | ---------------------- | ---------------------------------------- |
| ホームのステータス                                               | 今の段階   | 64px（余白を切り取る） | 「<名前> のすがた（<段階の名前>）」      |
| 吹き出しの横（今日の日記の入力欄・書いたあと・後から書く入力欄） | 今の段階   | 48px（余白を切り取る） | 読み上げない（飾り）                     |
| 名前の入力と確認                                                 | 段階 1     | 220px                  | 読み上げない                             |
| 振り返りの「ホームで名前を付けてね」                             | 段階 1     | 160px                  | 読み上げない                             |
| 振り返りの「まだ日記がないよ」                                   | 今の段階   | 160px                  | 読み上げない                             |
| 保存データが壊れているときのお知らせ                             | 段階 1     | 160px                  | 読み上げない                             |
| すがたが変わったお知らせ                                         | 新しい段階 | 240px                  | 読み上げない（見出しで同じことを伝える） |

- 「余白を切り取る」：段階ごとに決めた、キャラクターのいる正方形の範囲だけを枠いっぱいに見せる。枠の大きさとレイアウトは変えずに、キャラクターを大きく見せるため
- ステータスでは、キャラクターの名前の横に、段階の名前を小さな枠で出す。ステータスの区画の上下の余白は 12px
- 今日の日記の入力欄の高さは 200px

### すがたが変わったお知らせ

- 日記を書いて（ホームで今日の日記を書いても、振り返りで後から書いても）次の段階のレベルに上がると、いつものレベルアップのお知らせの代わりに出る
  - 新しい段階の絵（240px）
  - 見出し「<名前> が <段階の名前> になった！」
  - 「レベル <N> になったよ」
  - 「とじる」
- 開くと「とじる」にフォーカスがあり、「とじる」か Esc キーで閉じる（いつものレベルアップのお知らせと同じしくみ）
- 同じ段階の中でレベルが上がったときは、これまでどおり「🎉」「<名前> が レベル <N> になった！」「これからもよろしくね」
- 段階が変わったかは、保存する前のレベルと、経験値を足したあとのレベルの段階を比べて決める（一度に 2 つ以上上がっても同じ）

### レベルが下がったとき

- ステータスの絵と段階の名前は経験値から毎回決まるので、日記を消して前の段階のレベルに戻れば、そのまま前の段階になる
- 消す前の確認では、前の段階に戻るときだけ、レベルが下がる文の下に「すがたも前にもどるよ。」を注意の色で出す

### ファビコン

- `src/app/icon.svg`。Next.js の決まった置き場所なので、どのページにもタブのアイコンとして組み込まれる。Next.js の初期のアイコン（`favicon.ico`）は消した
- 中身は段階 1（ねこだま）の絵の写しで、しっぽ・ひげ・足元の影を外し、体と顔だけを枠いっぱいに見せる（小さいタブでも見えるように）
- 段階 1 の絵を描き直したときは、ファビコンの写しも作り直す

## 絵のファイルの安全

- 絵は `<img>` で画像として表示する（SVG の中にプログラムがあっても動かない形）。Next.js の `next/image` は使わない
- 絵（5 枚）とファビコンの中に、スクリプト・動きの指定・リンク・画像の埋め込み・ほかの形式の埋め込み・外部の読み込み・図形にしていない文字が入っていないことを、テストで毎回確かめる
- 絵は同じオリジンから読み込み、外部へは通信しない

## ページ全体

- 幅 375px で、名前の入力・ホーム・すがたが変わったお知らせのどれでも、横スクロールが出ない
