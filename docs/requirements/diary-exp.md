# 要件定義：日記で経験値（diary-exp）

実装（`feat/diary-exp` の `e760057` 時点）のコードとテストから書き起こし、⑧ の差分確認で決めた対応（AC-24・AC-25 の追加、CI への本番ビルドの追加）を反映した、この機能が実際に満たしている要件。計画との比較は [gap-report.md](../aidlc/diary-exp/gap-report.md) にある。

## 概要

初めて開いた人がキャラクターに名前を付け、1 日 1 件の日記を書くと、キャラクターに経験値が入りレベルが上がる。データはその端末のブラウザ（localStorage）だけに保存する。

## 画面と動き

画面は 1 ページ（`/`）で、状態に応じて表示を切り替える。どの状態でも上部に見出し「logling」を表示する。

| 状態                               | 表示                                                                                                            |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| サーバーでの描画時                 | 見出しだけ（ブラウザで保存データと今の時刻を読んでから、下の画面を出す）                                        |
| 保存データが壊れている             | 「データを読み込めなかったみたい…」と「はじめからにする」                                                       |
| キャラクターがいない（名前の入力） | 🐣・「はじめまして！名前をつけてくれる？」・名前の入力欄・「この名前にする」                                    |
| キャラクターがいない（名前の確認） | 「『<名前>』でいい？」・「名前はあとから変えられないよ」・「これにする」・「えらびなおす」                      |
| 今日の日記がない                   | ステータス・日付・「今日はどんな一日だった？きかせて！」・入力欄・文字数・「日記をのこす」                      |
| 今日の日記がある                   | ステータス・日付・「今日も書いてくれてありがとう！また明日ね」・本文・「次の日記は、明日の朝 4 時から書けるよ」 |

- ステータス：🐣・名前・「Lv. N」・経験値のバー（読み上げ機能向けに値を持つ）・「あと N でレベルアップ」・「今のレベル内の経験値 / 必要な量」
- 名前の確認では、確認の文にフォーカスを移す。「えらびなおす」で入力欄に戻り、入力した名前とフォーカスを戻す
- 日記を保存すると、上部に「✨ +10 経験値！」を 2.5 秒表示する。レベルが上がったときは、中央にお知らせ（「<名前> が レベル N になった！」「これからもよろしくね」「とじる」）を出す。お知らせは `<dialog>` で、開くと「とじる」にフォーカスがあり、「とじる」か Esc キーで閉じる
- （`streak` で変更）上部のお知らせは角の丸い四角にした。連続記録の区切りに届いた日は、2 行目に「🔥 7 日連続！ボーナス +20」が加わり、経験値もボーナスの分だけ多く入る。ステータスの経験値のバーの下には、🔥 の連続記録の帯が出る。詳しくは [streak の要件定義](streak.md) を参照

## ルール

| 項目         | ルール                                                                                                                                                                                                                    |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 名前         | 前後の空白（全角を含む）を取り除いて 1〜10 文字。見た目の 1 文字を 1 と数える（絵文字・合成文字も 1）。空なら「名前を入れてね」、11 文字以上なら「名前は 10 文字までにしてね」                                            |
| 本文         | 前後の空白・改行を取り除いて 1〜2000 文字（途中の改行は残す）。空なら「なにか書いてくれるとうれしいな」、2001 文字以上なら「2000 文字までにしてね（いま N 文字）」。入力中の文字数を表示し、2000 を超えると注意の色にする |
| 経験値       | 日記 1 件で 10。次のレベルまでに必要な量は「20 + 10 × 今のレベル」（Lv1→2 は 30）。レベルの上限はない                                                                                                                     |
| 1 日の区切り | 端末の時刻で朝 4 時。4 時より前に保存した日記は前の日の日記。1 日 1 件で、その日の日記があれば入力欄の代わりに日記を表示する                                                                                              |
| 日付の表示   | 「2026年10月28日（水）」の形（全角かっこ）                                                                                                                                                                                |
| 今日の判定   | 開いたとき、保存するとき、画面に戻ってきたとき（タブの切り替え・ウィンドウのフォーカス）に、今の時刻から計算し直す                                                                                                        |

## データの保存

- localStorage のキー `logling:v1` に、`{ version: 1, character: { name, totalExp } | null, entries: [{ date, body, createdAt }] }` を JSON で保存する
- 保存するのは名前と経験値の合計だけで、レベルと進み具合は合計から計算する
- （`diary-history` で追加）キャラクターに始めた日 `startDate`（名前を付けた日）、日記に後から書いた印 `writtenLater: true` を加えた。どちらもないデータもそのまま読めるため、`version` は 1 のまま。詳しくは [diary-history の要件定義](diary-history.md) を参照
- （`streak` で追加）連続記録の区切りに届いた日記に、ボーナスの量 `bonus` と連続日数 `bonusDays` をセットで加えた。`version` は 1 のまま
- 読み込み時に形をチェックし、JSON として読めない・形が合わない場合は「壊れている」として扱う
- 「はじめからにする」を選ぶと、元のデータを `logling:v1:broken:<日時>` に移してから、初めての状態に戻す
- 別のタブでデータが変わったら、表示を更新する（ブラウザの `storage` イベント。AC-25）
- ブラウザが保存を禁止していて読み込めない場合は、初めての状態として表示する（その後の保存は失敗する）
- アプリから外部への通信（`fetch` など）は行わない

## エラーとまれなケース

| 場面                       | 動き                                                                                                    |
| -------------------------- | ------------------------------------------------------------------------------------------------------- |
| 日記の保存に失敗           | 「⚠ 保存できなかった…少し時間をおいて、もう一度ためしてね」を表示。入力した文章は残り、経験値は入らない |
| 名前の保存に失敗           | 同じメッセージを表示し、名前の確認の画面のままになる（もう一度「これにする」を押せる。AC-24）           |
| 「はじめからにする」に失敗 | 同じメッセージを表示する                                                                                |
| 開いたまま朝 4 時を過ぎた  | 画面に戻ったとき、または保存するときに、次の日として扱う                                                |

## ページ全体

- 言語は日本語（`lang="ja"`）、タブのタイトルは「logling」
- フォントは端末の標準の日本語フォント（外部から取得しない）
- 背景はクリーム色、文字はこげ茶。端末の暗い設定には切り替えない
- 幅は最大 480px で中央に寄せる。長い英字や URL も折り返し、幅 375px で横スクロールが出ない
- ボタンと入力欄は高さ 44px 以上
