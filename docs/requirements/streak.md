# 要件定義：連続記録とボーナス（streak）

実装（`feat/streak` の `b2e130a` 時点）のコードとテストから書き起こし、⑧ の差分確認で決めた対応（AC-23 の追加、AC-15・AC-19 の文の更新）を反映した、この機能が実際に満たしている要件。計画との比較は [gap-report.md](../aidlc/streak/gap-report.md) にある。

## 概要

ホームで、日記を何日続けて書けているかと、次の区切りの日数まであと何日か・届くと入るボーナス経験値がわかる。今日の日記を書いて連続が区切りの日数に届くと、いつもの経験値にボーナスが加わる。データは `diary-exp`・`diary-history` と同じく、その端末のブラウザ（localStorage）だけに保存する。

## 画面と動き

### ホームの 🔥 の帯

キャラクターのステータス（名前・レベル・経験値のバー）の中、経験値のバーのすぐ下に、薄いはちみつ色の帯を出す。名前を付ける前と、保存データが壊れているときは、ステータスごと出ない。

| 状態                               | 1 行目                               | 2 行目                                 |
| ---------------------------------- | ------------------------------------ | -------------------------------------- |
| 今日の日記がある                   | 「🔥 5 日連続」                      | 「あと 2 日で 7 日連続。ボーナス +20」 |
| 今日まだ・昨日まで続いている       | 「🔥 4 日連続中。今日書くと 5 日！」 | 「あと 3 日で 7 日連続。ボーナス +20」 |
| 今日まだ・昨日も日記がない（0 日） | 「🔥 今日書くと 1 日目！」           | 「あと 3 日で 3 日連続。ボーナス +10」 |

- 「あと何日」は今日を含めて数える（次の区切りの日数 − 今の連続日数）
- 「0 日連続」とは表示しない
- 帯には「連続記録」という名前を付け、読み上げ機能でもまとまりがわかるようにする。🔥 は飾りとして読み上げない
- 日記を保存すると、その場で帯が変わる（例：「今日書くと 5 日！」→「5 日連続」）

### ボーナスのお知らせ

- 今日の日記を書いて区切りの日数に届いたときは、上部のお知らせが 2 行になる：「✨ +10 経験値！」「🔥 7 日連続！ボーナス +20」
- 区切りでない日は、これまでどおり 1 行（「✨ +10 経験値！」）
- お知らせは 1 行でも 2 行でも、角の丸い四角で、文字は中央にそろえる。出ている時間は 2.5 秒
- ボーナスを含めた経験値で次のレベルに届いたときは、`diary-exp` と同じレベルアップのお知らせを出す

### 振り返りで消すとき

- ボーナスの付いた日記を消す確認では、減る経験値はボーナスを含めた合計（例：「消すと経験値が 30 減るよ。」）
- そのときだけ、内訳を小さく出す：「（日記の 10 と、7 日連続のボーナス 20）」
- 消すと、日記の経験値とボーナスが一緒に減る。ほかの日記に付いたボーナスはそのまま残る

## ルール

| 項目               | ルール                                                                                                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 連続日数           | 日記がある日が途切れずに続いている日数。今日の日記があれば今日まで、なければ昨日までで数える。昨日もなければ 0。日付は朝 4 時で区切る                                  |
| 後から書いた日記   | 連続日数に数える（空いた日を後から埋めると、連続がつながる）                                                                                                           |
| 区切りとボーナス   | 3 日：+10、7 日：+20、14 日：+30、30 日：+50、そのあと 15 日ごと（45・60・75 日…）：+50                                                                                |
| ボーナスが入るとき | ホームで今日の日記を書き、「昨日までの連続日数 + 1」が区切りの日数のときだけ。後から書いた日記で区切りに届いても入らない（その区切りは取り逃がす）                     |
| 途切れたあと       | 次に書いた日が 1 日目になる。また区切りに届けば、ボーナスはもう一度入る                                                                                                |
| 消したとき         | ボーナスはその日の日記に付いた経験値として、日記と一緒に減る。消して同じ日に書き直すと、区切りならボーナスはもう一度入る（消したときに減っているので二重にはならない） |
| 書き直したとき     | ボーナスは変わらない                                                                                                                                                   |
| これまでの日記     | この機能より前に書いた日記も連続日数に数える。過去に区切りに届いていた分のボーナスは、さかのぼって入れない                                                             |

## データの保存

- `diary-exp` と同じキー `logling:v1` に保存する。`version` は 1 のまま
- ボーナスが入った日記にだけ、`bonus`（ボーナスの量）と `bonusDays`（ボーナスが入ったときの連続日数。確認の内訳に使う）を記録する
- 読み込み時に、`bonus` と `bonusDays` が両方ないか、両方とも 1 以上の整数かを確かめる。片方だけ、またはおかしな値なら、壊れたデータとして扱う
- 日記ごとの経験値は「日記の分（その日に書いたなら 10、後から書いたなら 5）+ `bonus`」
- 連続日数は保存せず、保存されている日記から毎回計算する
- アプリから外部への通信は行わない（7 日目を書いてボーナスが入るまでの間も、同じオリジン以外へ通信せず、本文も送らない）

## エラーとまれなケース

| 場面                              | 動き                                                                                |
| --------------------------------- | ----------------------------------------------------------------------------------- |
| 今日の日記の保存に失敗            | 「⚠ 保存できなかった…」を出す。日記・経験値・ボーナスは変わらず、お知らせも出さない |
| 開いたまま朝 4 時を過ぎてから保存 | 保存するときに日付を計算し直し、その日付で連続日数とボーナスを求める                |

## ページ全体

- 幅 375px で、帯・ボーナスのお知らせ・内訳の出る確認の窓のどれでも、横スクロールが出ない
