# 要件定義：日記の振り返り（diary-history）

実装（`feat/diary-history` の `5786066` 時点）のコードとテストから書き起こし、⑧ の差分確認で決めた対応（AC-25〜AC-27 の追加、AC の文の更新）を反映した、この機能が実際に満たしている要件。計画との比較は [gap-report.md](../aidlc/diary-history/gap-report.md) にある。

## 概要

ホームとは別の振り返りのページ（`/history`）で、これまでの日記を新しい順に読める。今日を含めた最近 7 日分の日記は書き直したり消したりでき、最近 7 日のうち日記がない日（始めた日以降）には後から書ける。データは `diary-exp` と同じく、その端末のブラウザ（localStorage）だけに保存する。

## 画面と動き

### ホーム

- キャラクターがいるときだけ、上の帯の右に「ふりかえる ›」（`/history` へのリンク）を出す。名前を付ける前と、保存データが壊れているときは出さない

### 振り返りのページ

上の帯の左に「‹ ホーム」（`/` へのリンク）、真ん中に「logling」を出す。タブのタイトルは「ふりかえり | logling」。

| 状態                                    | 表示                                                                                  |
| --------------------------------------- | ------------------------------------------------------------------------------------- |
| サーバーでの描画時                      | 上の帯だけ                                                                            |
| 保存データが壊れている                  | 「データを読み込めなかったみたい…」と「ホームへ」                                     |
| キャラクターがいない                    | 🐣・「ホームで名前を付けてね」・「ホームへ」                                          |
| キャラクターはいるが、日記が 1 件もない | 🐣・「まだ日記がないよ。ホームで今日の日記を書いてみよう」・「ホームへ」              |
| 日記がある                              | 見出し「ふりかえり」・「最近 7 日の日記は、書き直したり消したりできるよ」・日記の一覧 |

### 一覧

日付の新しい順に、1 日 1 枚のカードを並べる。日付は年を省いた「11月7日（土）」の形。

| カード                                      | 表示                                                                                                                                    |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 最近 7 日の日記                             | 日付・「あとから」の印（後から書いた日記だけ）・本文（改行もそのまま）・「書き直す」「消す」                                            |
| 空いた日（今日より前の 6 日、始めた日以降） | 点線のカード・日付・「この日はまだ書いていないよ（あとから書くと +5 経験値）」・「この日の日記を書く」                                  |
| 8 日以上前の日記                            | 区切りの文「― ここから下は 8 日以上前の日記（読むだけ） ―」のあとに、日付・印・本文（ボタンなし）。8 日以上前がなければ区切りも出さない |

- 今日の日記がない日でも、今日は空いた日のカードにしない（今日の日記はホームで書く）
- 最近 7 日のリストと 8 日以上前のリストは別の `<ul>` にし、区切りの文はその間に置く
- 入力できるカードは 1 枚だけ。書き直し中・後から書く途中は、ほかのカードのボタン（「書き直す」「消す」「この日の日記を書く」）を出さない

### 書き直す

- 「書き直す」を押すと、カードの中が入力欄に変わる。今の本文と文字数が入り、入力欄にフォーカスが移る。ボタンは「保存する」「やめる」
- 保存すると本文が変わる。経験値とレベルは変わらず、お知らせも出さない。「やめる」で入力欄を閉じ、本文は元のまま

### 消す

- 「消す」を押すと、画面の中央に確認の窓（`<dialog>`）を出す
  - 「<月>月<日>日の日記を消す？」
  - 「消すと経験値が <10 または 5> 減るよ。」（その日に書いた日記は 10、後から書いた日記は 5）
  - （`streak` で追加）連続記録のボーナスが付いた日記は、減る量がボーナスを含めた合計になり、内訳「（日記の 10 と、7 日連続のボーナス 20）」も出す
  - （`character-evolution` で追加）消すとキャラクターのすがたが前の段階に戻るときは、「すがたも前にもどるよ。」も出す
  - レベルが下がるときだけ「<名前> のレベルが <N> から <M> に下がるよ。」（注意の色）
  - 「消した日記は元に戻せないよ」
  - 「消す」（注意の色）・「やめる」
- 開いたときは「やめる」にフォーカスがある。「やめる」か Esc キーで閉じると、何も変わらない
- 「消す」で日記を消し、その日記で入った経験値を減らす（0 より下にはならない。必要な量を下回ればレベルも下がる）。消した日が最近 7 日（今日を除く）で始めた日以降なら、空いた日のカードに変わる。今日の日記を消すと、ホームでもう一度書ける

### 後から書く

- （`character-evolution` で変更）この文書の 🐣 は、すべてキャラクターの絵になった。「ホームで名前を付けてね」は段階 1、「まだ日記がないよ」と後から書く入力欄の問いかけは今の段階の絵。後から書いて次の段階のレベルに上がったときは、すがたが変わったお知らせが出る。詳しくは [character-evolution の要件定義](character-evolution.md) を参照
- 「この日の日記を書く」を押すと、カードの中が入力欄に変わる。🐣「<月>月<日>日は、どんな一日だった？」・空の入力欄（案内「思い出せることを書いてみよう」）・文字数・「日記をのこす」「やめる」
- 保存すると、その日の日記として一覧に入り、「あとから」の印が付く。経験値が 5 入り、上部に「✨ +5 経験値！」を出す。レベルが上がったときは `diary-exp` と同じレベルアップのお知らせを出す
- 後から書いた日記は、そのまま「書き直す」「消す」ができる

## ルール

| 項目           | ルール                                                                                                                                                                            |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 最近 7 日      | 今日を含めた 7 日。「今日」は `diary-exp` と同じく朝 4 時で区切る（例：11 月 7 日 3 時 59 分は 11 月 6 日なので、10 月 31 日〜11 月 6 日）                                        |
| 書き直す・消す | 最近 7 日の日記だけ。8 日以上前の日記は読むだけ                                                                                                                                   |
| 後から書く     | 今日より前の 6 日のうち、日記がない日で、始めた日以降の日だけ。1 日 1 件のきまりは変わらない                                                                                      |
| 始めた日       | 名前を付けた日（朝 4 時で区切った日付）。日記を書いていなくても、その日になる。`diary-exp` で名前を付けた（記録がない）データは、一番古い日記の日を始めた日とみなす               |
| 経験値         | その日に書いた日記は 10、後から書いた日記は 5。書き直しでは変わらない。消すと、その日記の分が減る。後から書いた印のない日記（`diary-exp` の日記）は、その日に書いた日記として扱う |
| 本文           | `diary-exp` と同じ（前後の空白・改行を除いて 1〜2000 文字。エラーの文言も同じ）                                                                                                   |
| 今日の判定     | 画面の表示は `diary-exp` と同じ。書き直し・消す・後から書くを保存するときは、その場で計算し直す                                                                                   |

## データの保存

- `diary-exp` と同じキー `logling:v1` に保存する。`version` は 1 のまま
- 日記に、後から書いたことを示す `writtenLater: true` を加えた（後から書いた日記だけに付く）
- （`streak` で追加）連続記録の区切りに届いた日記には `bonus`・`bonusDays` が付く。その日記の経験値はボーナスを含めた合計で、消すと一緒に減り、書き直しでは変わらない。後から書いた日記には付かない。詳しくは [streak の要件定義](streak.md) を参照
- キャラクターに、始めた日 `startDate`（"YYYY-MM-DD"）を加えた。名前を付けたときに保存する
- 始めた日の記録がないデータは、書き直す・消す・後から書くを保存するときに、その時点の始めた日（一番古い日記の日）を書き込む。一番古い日記を消しても、始めた日はずれない
- 読み込み時に、`writtenLater` は「ない」か `true`、`startDate` は「ない」か "YYYY-MM-DD" の形かを確かめる。違えば壊れたデータとして扱う
- 日記は日付の古い順に並べて保存する
- アプリから外部への通信は行わない（振り返りの操作の間も、同じオリジン以外へ通信せず、本文も送らない）

## エラーとまれなケース

| 場面                                                               | 動き                                                                                                                                |
| ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| 書き直し・後から書くの保存に失敗                                   | 「⚠ 保存できなかった…少し時間をおいて、もう一度ためしてね」を出す。入力欄は開いたままで、書いた文章も残る。日記と経験値は変わらない |
| 削除の保存に失敗                                                   | 確認の窓を閉じ、同じメッセージを出す。日記と経験値は変わらない                                                                      |
| 開いたまま朝 4 時を過ぎて、書き直す・消す日記が 8 日以上前になった | 保存せず、「⚠ この日記は、もう書き直したり消したりできないよ」を出す。入力欄は閉じる                                                |
| 開いたまま朝 4 時を過ぎて、後から書く日が 8 日以上前になった       | 保存せず、「⚠ この日には、もう後から書けないよ」を出す。入力欄は閉じる                                                              |
| 日記を消して 1 件もなくなった                                      | 「まだ日記がないよ」の案内になる（日記が 1 件もないときは、後から書くこともできない）                                               |

## ページ全体

- 色・フォント・幅（最大 480px）・ボタンの高さ（44px 以上）は `diary-exp` と同じ
- 幅 375px で、一覧・書き直し・後から書く・確認の窓のどれでも横スクロールが出ない（長い英字も折り返す）
