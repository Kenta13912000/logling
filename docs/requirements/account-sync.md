# 要件定義：ログインとクラウド保存（account-sync）

実装（`feat/account-sync-app` の `d344ff1` 時点。土台は PR-1 の `feat/account-sync`）のコードとテストから書き起こした、この機能が実際に満たしている要件。計画との比較は [gap-report.md](../aidlc/account-sync/gap-report.md) にある。技術の選定は [ADR-0005](../adr/0005-db-auth-neon-better-auth.md)・[ADR-0006](../adr/0006-auth-environments-and-test-login.md)。

## 概要

ログインは任意で、方法は Google アカウントだけ。ログインしなければ、これまでどおりブラウザの中に保存して使える。ログインすると、キャラクターと日記はインターネット上の保管場所（Neon。シンガポール）に保存され、ほかのスマホや PC でも同じアカウントで続きが書ける。ログイン前にブラウザで育てたキャラクターは、ログインしたときにアカウントへ引き継げる。日記は、ログインした本人しか読み書きできない。

## 画面と動き

### ログインの入口

- ホームの上の帯に「アカウント ›」（名前を付ける前も出る）。名前を付ける前の画面には「ほかの端末で使っていた人は ログイン ›」
- どちらも `/account`（アカウントの画面）へ

### アカウントの画面（`/account`）

| 状態                               | 出るもの                                                                                                                                                                                                                                                                                                                 |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ログインしているかを確かめている間 | 「Google でログイン」も「ログアウト」も出さない（押し間違いを防ぐ）                                                                                                                                                                                                                                                      |
| ログインしていない                 | 「ログインすると、スマホでも PC でも、同じキャラクターと日記で続きが書けるよ」、「日記はインターネット上の保管場所にしまわれ、あなたしか読めない」「このブラウザのキャラクターと日記は、そのまま引き継げる」、Google の決まりの見た目の「Google でログイン」、「ログインしなくても、このブラウザの中に保存して使えるよ」 |
| ログイン中                         | 「ログイン中」とメールアドレス、「☁ 日記はインターネット上の保管場所にしまわれているよ。…」、「ログアウト」と「ログアウトすると、この端末には日記もキャラクターも残らないよ」、いちばん下に注意の色の「退会する」                                                                                                        |
| どちらでも                         | 「日記の保存のしかた ›」（説明ページへ）、上の帯の「‹ ホーム」                                                                                                                                                                                                                                                           |

- 「Google でログイン」は、毎回アカウントを選ぶ画面を出す（共用の端末で、前の人のアカウントで入らないように）。許可するとホームに戻る
- Google の画面でやめた・失敗したとき（`/account?error=login`）や、ログインを始められなかったときは「⚠ ログインできなかった…もう一度ためしてね。このブラウザの日記はそのまま残っているよ」。ブラウザの中のデータには触れない
- 「ログアウト」でホームへ。ログアウトに失敗したときは、ホームに戻らず「⚠ ログアウトできなかった…通信できるところで、もう一度ためしてね」（共用の端末で「ログアウトしたつもり」を防ぐ）

### 退会

- 「退会する」で確認が出る：「退会する？」、「ぴよ（Lv. 6）と日記 12 件が、すべて消えるよ。」（キャラクターがいないか、読み込めなかったときは「アカウントの記録が、すべて消えるよ。」）、「元にはもどせないよ。」、「Google アカウントそのものは消えないよ」、「退会する」・「やめる」
- **ログインして 1 日以内**なら、確認のあと退会し、ホーム（名前を付ける画面）へ。同じ Google アカウントでまたログインすると、空の新しいアカウントになる
- ログインして 1 日より前なら、「本人の確認のため、もう一度ログインしてね」「Google でログインし直す」。ログインし直すと `/account?withdraw=again` に戻り、退会の確認がもう一度出る
- 退会できなかったときは「⚠ 退会できなかった…通信できるところで、もう一度ためしてね」。何も消えない

### ホームと振り返り（ログイン中）

| 場面                                         | 表示                                                                                                                                                                                                           |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 読み込み中                                   | 「読み込んでいるよ…」（ログインしていない人も、ログインを確かめる一瞬だけ出る）                                                                                                                                |
| 読み込めなかった                             | 「データを読み込めなかった…」「通信できるところで、もう一度ためしてね」「もう一度読み込む」。名前を付ける画面は出さない                                                                                        |
| 保存している間                               | 「日記をのこす」「保存する」「これにする」が「保存しているよ…」になり、押せない（ログインしていないときも同じ。一瞬で終わる）                                                                                  |
| 保存できなかった                             | ホーム：「⚠ 保存できなかった…通信できるところで、もう一度「日記をのこす」を押してね」。振り返り：「…もう一度ためしてね」。データは変わらず、書いていた文は入力欄に残る                                         |
| ほかの端末で今日の日記がもう書かれていた     | 「⚠ ほかの端末で、今日の日記がもう書かれていたよ。最新の内容を表示したよ」。ほかの端末の日記の下に「この端末で書いていた文（保存されていないよ）」の枠と「必要なら、コピーして振り返りの画面から書き直してね」 |
| ほかの端末で、もうキャラクターが作られていた | 「⚠ ほかの端末で、もうキャラクターが作られていたよ。そのキャラクターを表示したよ」                                                                                                                             |
| 振り返りで、ほかの端末で変わっていた         | 「⚠ ほかの端末で変わっていたよ。最新の内容を表示したよ」。書き直す・後から書くのときは、入力欄を閉じ、ページの上に書いていた文の枠と「必要なら、コピーしてもう一度書いてね」                                   |

### ブラウザのデータの引き継ぎ（ホーム）

| ブラウザ                   | アカウント | 動き                                                                                                                                                                                                                                                                                                        |
| -------------------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| キャラクターがいる         | いない     | 「アカウントに移しているよ…」のあと、ブラウザの中を消して「☁ ぴよ と日記 12 件をアカウントに移したよ」（4 秒で消える）                                                                                                                                                                                      |
| キャラクターがいる         | いる       | 「どちらのキャラクターで続ける？」に、「このブラウザ」「アカウント（ほかの端末）」の絵・名前・段階・「Lv. 6・日記 12 件」と「ぴよ で続ける」。選ぶと確認：「ぴよ で続ける？」「アカウントの たま（Lv. 3・日記 5 件）は消えるよ。」「元にはもどせないよ。」「たま を消して ぴよ で続ける」・「えらびなおす」 |
| いない・壊れていて読めない | どちらでも | 何もしない                                                                                                                                                                                                                                                                                                  |

- ブラウザの方を選ぶと、アカウントのデータを置き換えて、ブラウザの中を消す。アカウントの方を選ぶと、ブラウザの中を消すだけ
- 引き継ぎが終わるまでは、日記を書く画面を出さない
- 移せなかったときは「⚠ 移せなかった…通信できるところで、もう一度ためしてね」「このブラウザの日記は、そのまま残っているよ」「もう一度移す」
- データが大きすぎて一度に送れないとき（3.8MB を超える）は、「⚠ 日記が多すぎて、まとめて移せなかった…このブラウザの日記は、そのまま残っているよ」を出し、アカウントのデータで使えるようにする

### 説明ページ「日記の保存のしかた」（`/privacy`）

- ログインしていなくても開ける。ホームのフッター・アカウントの画面から行ける
- 見出し：ログインしないで使うとき／ログインして使うとき／Google から受け取るもの／だれが読めるか／ログアウトと退会／Google でのログインの許可を取り消すには／問い合わせ（GitHub の Issues）。最後に最終更新日
- だれにでもわかる言葉で書く。「クラウド」「DB」「データベース」「サーバー」「トークン」「ID」「ストレージ」は使わない（テストで確かめる）

### ホームのフッター

- 「logling：日記を書くとキャラクターが育つ、続けたくなる日記アプリ」と「日記の保存のしかた」（Google のブランドの確認で、ホームページにアプリの説明と説明ページへのリンクが求められるため）

## ルール

| 項目                | ルール                                                                                                                                                                                         |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 保存先              | ログインしていなければブラウザの中（`logling:v1`。これまでどおり）。ログイン中はインターネット上の保管場所だけで、ブラウザの中には書き込まない                                                 |
| 保存の単位          | 「キャラクターを作る」「日記を足す（増える経験値つき）」「本文を書き直す」「日記を消す（減る経験値つき）」の操作ごと。丸ごと上書きしない（ほかの端末の変更を消さない）                         |
| 経験値              | 量（10・後から書いた 5・ボーナス）はブラウザで計算する（朝 4 時の区切りと「今日」は端末の時刻で決まるため）。サーバーは 0〜60 の整数かだけを確かめ、足し算・引き算で変える（0 より下がらない） |
| 1 日 1 件           | 保管場所の決まり（人 ＋ 日付が主キー）で守る。2 つの端末で同時に書いても 2 件にならない                                                                                                        |
| 始めた日            | `diary-exp` のころのキャラクター（始めた日がない）は、日記を足す・書き直す・消すときに、いちばん古い日記の日を始めた日として記録する。すでにあれば変えない                                     |
| ログインの有効期間  | 60 日。使うと 1 日に 1 回延びる                                                                                                                                                                |
| Google から残す情報 | メールアドレスと、Google アカウントを見分ける番号だけ。表示名・アイコン・Google のトークン（アクセス・リフレッシュ・ID）は、保存する直前に外す                                                 |
| 退会の条件          | ログインして 1 日以内。人を 1 つの命令で消し、ログインの記録・Google の記録・キャラクター・日記は連鎖削除でいっしょに消える                                                                    |
| 引き継ぎ            | まとめて 1 つのトランザクションで移す。経験値・始めた日・後から書いた印・ボーナスはそのまま。1 件でもおかしければ何も移さない                                                                  |

## 本人だけが読み書きできる守り方（AC-29）

- 保管場所には logling のサーバーからだけつなぐ。つなぎ先（秘密の値）はサーバーだけが持つ
- 日記とキャラクターの読み書きは、すべて `src/features/cloud/repository.ts` を通し、どの関数も「人の ID」でしぼる
- サーバーの処理（Server Actions）は人の ID を引数に取らず、毎回サーバーでログインの情報から取り出す。ログインしていなければ、保管場所に触れずに断る
- サーバーは、送られてきた日記・キャラクター・経験値・日付の形を確かめる。失敗の記録にはエラーの種類だけを残す（日記の本文を記録に残さない）

## 環境と秘密の値（ADR-0006）

| 環境                       | 保管場所            | Google ログイン                    |
| -------------------------- | ------------------- | ---------------------------------- |
| 本番（logling.vercel.app） | Neon の `main` の枝 | 使える                             |
| 手元の開発・E2E テスト     | Neon の `dev` の枝  | 使える（E2E はテスト用のログイン） |
| PR ごとの確認用の公開      | なし                | 使えない                           |

- 秘密の値（`DATABASE_URL`・`BETTER_AUTH_SECRET`・`BETTER_AUTH_URL`・`GOOGLE_CLIENT_ID`・`GOOGLE_CLIENT_SECRET`）は、Vercel の環境変数（Production）と手元の `.env.local` だけに置く
- テスト用のログイン（メールアドレスとパスワード）は、`LOGLING_E2E_AUTH=1` があり、かつ本番でないときだけ有効
- Vercel の関数はシンガポール（`vercel.json` の `regions: ["sin1"]`）
- Server Actions に一度に送れる大きさは 4MB（`next.config.ts`）
- 表の変更は `npm run db:migrate` で、`dev`、`main` の順に開発者の手元から当てる
- E2E のあと、`dev` の枝から `e2e-…@example.com` のテスト用の人を片付ける

## エラーとまれなケース

| 場面                                             | 動き                                                                                |
| ------------------------------------------------ | ----------------------------------------------------------------------------------- |
| 確認用の公開でログインしようとした               | 「ログインできなかった」のお知らせ（その環境では使えない）                          |
| 同じ日を 2 つの端末で同時に書いた                | 先に届いた方だけが残る。あとの方には「ほかの端末で…」のお知らせと、書いていた文の枠 |
| 同じ日記を 2 つの端末で書き直した                | あとから保存した方の本文が残る。お知らせは出さない                                  |
| 何もしていない画面が、ほかの端末の変更を知らない | 保存したとき、または開き直したときに取り込む（自動では読み直さない）                |
| 引き継ぎ中にほかの端末でキャラクターが作られた   | 選ぶ画面になる                                                                      |
| 退会の途中で失敗した                             | 何も消えない                                                                        |
